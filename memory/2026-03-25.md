### 黄金3秒法则
```
第1秒：视觉冲击
第2秒：情绪钩子
第3秒：悬念留白
```

### 核心观点
> 开头的本质是"情绪炸弹"，不是介绍。
> 爆款开头的核心是"戳痛点"，不是炫技。
> 痛感类型：背叛之痛、欺压之痛、失去之痛。

### 开头公式
```
数字要小（3年、100万、10亿）
反差要大（乞丐→首富、废物→天才）
钩子要狠（接下来会怎样？）
```

### 核心收获

#### 基础转折词
```
闻言，话落，听后，听到这话，这让我，这时
却，可，然而，但是，可是，只是，不过
不料，竟然，偏偏，可惜，见此情形
```

#### 关联词模板
| 关系 | 模板 |
|------|------|
| 转折 | 虽然…但是… / …却… |
| 假设 | 如果…就… / 即便…也… |
| 递进 | 不但…而且… / 不仅…还… |
| 因果 | 因为…所以… |
| 意外 | 谁知… / 不料… |

#### 衔接词速查
- 时间：随之、随后、接下来、顷刻之间
- 结果：终于、果然、不出所料、原来如此
- 解释：其实、实际上、换句话说
- 归纳：总之、一句话、总而言之
