## 🎭 人物一致性系统

### 核心流程
```
1. 提取人物/场景/道具 → LLM 分析小说
2. 生成基础图 → 每个角色生成一张基础形象图
3. 分镜生图 → 参考基础图 + 提示词生成
4. 保证一致性 → 相同人物使用相同基础图
```

### 图片生成策略
- **文字生图**：无参考图时，纯文字 prompt
- **垫图+提示词**：有基础图时，参考图 + prompt（提示词优先级更高）
- **图生视频**：分镜图片 → 视频片段
