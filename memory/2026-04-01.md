### 精品漫剧核心体系（小全亲授）

#### 运镜技巧
- 情绪爆发 → 慢动作 + 特写
- 打脸复仇 → 固定镜头 + 拉镜头
- 浪漫场景 → 缓慢推进 + 柔光
- 紧张悬疑 → 跟镜头 + 摇晃

#### 灯光公式
- 悲伤 → 头顶单灯 + 蓝色调
- 愤怒 → 红色调 + 底部打光
- 浪漫 → 柔光箱 + 逆光 + 金色
- 复仇 → 红色补光 + 深阴影
- 悬疑 → 强对比 + 单侧光

#### 空间逻辑
- 不越轴：摄像机在关系线同一侧
- 不瞬移：位置有移动过程
- 视线一致：A看B → B看A

#### 人物一致性系统
- 多参考 = 角色参考 + 表情参考 + 服装参考
- 首尾帧 = 镜1尾帧 = 镜2首帧
