| 模型 | 核心优势 | 提示词公式 |
|-----|---------|-----------|
| **可灵 Kling** | 最长视频（2分钟） | 主体（描述）+ 运动 + 场景 + 镜头/光影/氛围 |
| **Wan2.x** | 音画同步、多镜头 | 主体 + 场景 + 运动 + 声音描述 |

| **Grok Imagine** | 最快速度（17秒） | Scene + Style + Mood + Lighting + Camera |
| **Vidu** | 角色一致性极强 | 主体 + 动作 + 场景 + 镜头（支持多参考图） |
| **Runway Gen-4** | 视频编辑 | Subject + Action + Camera Movement |
| **Pika** | 简单易用 | Subject + Action + Style/Setting + Camera |
| **Luma Ray3** | 电影级HDR | Subject + Scene + Motion + Camera Control |
| **海螺** | 速度快 | 主体 + 场景 + 运动 + 镜头控制 |
| **Seedance** | 首尾帧控制 | 主体 + 场景 + 运动 + 镜头 |
| **HunyuanVideo** | 开源免费 | 主体 + 场景 + 运动 |
| **CogVideoX** | 开源免费 | 主体 + 场景 + 运动 |

**核心知识点**:

1. **文生视频 vs 图生视频**:
   - 文生视频：描述"有什么" + "怎么动"
   - 图生视频：只描述"怎么动"（运动+运镜）

2. **首帧/首尾帧**:
   - 首帧生视频：控制开头，AI推断后续
   - 首尾帧生视频：控制开头和结尾，AI填充过渡

3. **关键原则**:
   - 图生视频不要重复描述图片内容
   - 提示词语言要匹配模型
   - 首尾帧要有关联性
   - 运动描述要具体
