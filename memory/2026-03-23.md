## 🔧 视频状态检查Bug修复

### 🔴 问题诊断
小全反馈：后台显示15条视频成功10条，但程序显示全部失败

**根本原因**：
1. 状态码检查太严格，只认 `"succeed"`
2. 不同API返回不同的状态码（`"success"`, `"completed"`, `"SUCCESS"`等）
3. 轮询超时时间太短（3分钟），后台可能还在处理

### ✅ 修复内容

**1️⃣ 支持多种成功状态码**
```python
success_statuses = ["succeed", "success", "completed", "done", "finished"]
failed_statuses = ["failed", "failure", "error", "cancelled", "canceled"]
```

**2️⃣ 支持多种返回数据结构**
```python
videos = check_data.get("task_result", {}).get("videos", [])
if not videos:
    videos = check_data.get("result", {}).get("videos", [])
if not videos:
    videos = check_data.get("videos", [])
if not videos:
    video_url = check_data.get("video_url") or check_data.get("url")
```

**3️⃣ 增加轮询超时时间**
- 从 3分钟 → 5分钟
- 每30秒打印一次状态日志

**4️⃣ 增加调试日志**
- 状态检查异常打印
- 超时提示"后台可能仍在处理"
