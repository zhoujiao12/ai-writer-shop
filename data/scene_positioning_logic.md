# 场景站位逻辑 v1.0

> 固定场景的人物站位必须符合空间逻辑
> 更新时间：2026-03-31

---

## 🎯 站位核心原则

### 1. 人物关系决定站位

**对话场景：**
```
正打：摄像机拍A，背对B
反打：摄像机拍B，背对A
```
**要点：**
- 两人必须面向对方
- 中间留出视线走廊
- 不能背对背说话

**示例：**
```
❌ 错误站位：
A君 ←背→ B君 （背对背说话）

✅ 正确站位：
A君 ←面向→ B君 （面对面）
   ↖ 视线 ↗
   摄像机在中间
```

---

### 2. 主次关系决定位置

**视觉重心：**
- 主角放画面中心或三分线上
- 次要人物放边缘
- 反派可以放阴影侧

**三分法：**
```
┌───────┬───────┐
│       │ 主角  │
│  配角 ├───────┤
│       │ 配角  │
└───────┴───────┘
```

---

### 3. 空间逻辑

**室内场景：**
```
门 → 桌 → 床 → 窗（由近到远）
```
- 进入场景要有关门动作
- 不能突然出现在场景中央

**室外场景：**
```
石 → 桌 → 树 → 亭 → 墙（由近到远）
```
- 行走要有路线逻辑
- 不能瞬移

---

### 4. 常见场景站位

#### 对话站位

```
【两人对话 - 平视】

    A君 ←────→ B君
    ↖视线        ↗视线
    
摄像机位置：在两人中间，侧45度
```

```
【两人对话 - 正反打】

镜1（正打A）：A君在右，看向左边
镜2（反打B）：B君在左，看向右边

注意：A君在左，B君在右（镜像对称）
```

#### 三人对话

```
【三角站位】

        A君（主）
       ↗     ↖
      B       C（次）
      
摄像机：可从任意角拍摄
```

#### 多人场景

```
【等级站位】

    主位（嫡姐）
    
次位    次位
（配角）（配角）

位置由身份等级决定
```

---

### 5. 摄像机与站位关系

**镜头类型决定构图：**

| 镜头 | 站位要求 |
|-----|---------|
| 远景 | 全身，站位分散 |
| 中景 | 膝盖以上 |
| 近景 | 胸部以上 |
| 特写 | 只拍局部 |

**越近的镜头，站位越居中**

---

### 6. 视线逻辑

**对话视线：**
```
A君说话时 → 看B君方向
B君说话时 → 看A君方向
```

**提示词写法：**
```
A君：Looking at B君, slightly angry
B君：Looking at A君, smirking

Camera: Over-the-shoulder shot of A君
```

---

### 7. 场景连贯性

**同一场景的不同镜头：**
```
【同一室内 - 厅堂】

镜1（全景）：厅堂全貌，嫡姐坐主位
镜2（中景）：苏婉音进入，向嫡姐行礼
镜3（近景）：嫡姐表情，轻蔑地看着
镜4（过肩）：从嫡姐肩后拍苏婉音
镜5（中景）：苏婉音呈上佛经

空间逻辑：
- 苏婉音从门口进来
- 走向嫡姐面前
- 呈上佛经（位置固定）
```

**移动逻辑：**
```
起点（门）→ 中点（中途）→ 终点（嫡姐前）
```

## 📝 站位标注模板

**每镜必须标注：**
```
【场景：正厅 · 日】

站位图：
┌─────────────────┐
│    [主位 嫡姐]  │
│                 │
│    [次位]       │
│                 │
│    [苏婉音]→   │ ← 从门口进来
└─────────────────┘

镜1：全景，嫡姐坐主位，苏婉音在门口
镜2：中景，苏婉音走向嫡姐（从左向右）
镜3：近景，嫡姐表情，看向左侧（苏婉音方向）
镜4：过肩，从嫡姐右肩拍，苏婉音在左
镜5：中景，苏婉音停在嫡姐前，行礼
```

## 🚫 站位错误

| 错误 | 后果 | 解决 |
|-----|------|------|
| 背对背说话 | 不自然 | 改为面向对方 |
| 越轴 | 观众混乱 | 保持摄像机同侧 |
| 瞬移 | 穿帮 | 标注移动路线 |
| 视线不一致 | 不真实 | 标注看向方向 |
| 位置混乱 | 逻辑错误 | 画站位图 |
