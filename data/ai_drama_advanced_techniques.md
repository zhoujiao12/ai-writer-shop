## 🔧 分镜设计核心技巧

### 景别呼吸原则

**公式：**
```
远 → 中 → 近 → 特写 → 退回中/远
```

### 景别功能表

| 景别 | 用途 | 观众感受 |
|-----|------|---------|
| **远景** | 交代环境、氛围 | 疏离、宏观 |
| **全景** | 人物全身、关系 | 完整、客观 |
| **中景** | 膝盖以上、对话 | 平衡、参与 |
| **近景** | 腰部以上、情绪 | 亲近、交流 |
| **特写** | 局部细节、强调 | 聚焦、紧张 |

### 镜头运动

| 运动 | 效果 | 使用场景 |
|-----|------|---------|
| **推** | 聚焦、强调 | 情绪爆发 |
| **拉** | 交代、疏离 | 场景展开 |
| **摇** | 空间展示 | 室内外转 |
| **移** | 跟随、临场 | 追逐、行走 |
| **跟** | 聚焦人物 | 对话、行动 |

## ✍️ 提示词万能公式

### 图片提示词公式

```
【场景环境】+【角色动作】+【镜头描述】
```

**示例：**
```
古风府邸大厅，日光从窗棂射入
一位少女缓缓下跪行礼
中景，正面略微俯视，电影感
```

### 视频提示词公式

**Nano Banana Pro：**
```
[Subject + Adjectives] doing [Action] in [Location].
[Composition/Camera Angle].
[Lighting/Atmosphere].
[Style/Media].
[Specific Constraint].
```

**简化版：**
```
[谁] + [在做什么] + [场景] + [镜头] + [光线] + [风格]
```

## 🎭 人物一致性解决方案

### 方案一：智能参考（推荐）

**即梦AI方法：**
1. 上传基础角色图
2. 提示词公式：
   ```
   以上传人物为参考，更换为[场景]，穿着[服装]，保持五官和气质不变
   ```
3. 批量生成不同场景

### 方案二：Midjourney V7 Omni Reference

**参数：**
```
--v 7 --cref [角色图URL] --cw 80
```

**说明：**
- `--cw 80` = 保持身份，允许表情/角度变化
- `--cw 100` = 完全一致

### 方案三：Vidu R2V 2.0

**核心优势：**
- 支持7张参考图
- 3个角色同时一致
- 多人物场景首选

**使用方法：**
```
上传角色参考图 → 输入中文提示词 → 生成视频
```

### 方案四：首尾帧控制

**逻辑：**
```
首帧（起点）─→ AI填充过渡 ─→ 尾帧（终点）
```

**操作：**
1. 生成满意的第一镜
2. 确定第二镜的尾帧图
3. 使用"首帧生视频"功能
4. AI自动填充过渡

### 表情微调技巧

```
眼睛看向左下方（思考）
微微张嘴（惊讶）
眉头紧皱（愤怒）
嘴角上扬（微笑）
```

## 🔄 转场与衔接技巧

### AI转场类型

| 类型 | 效果 | 适用场景 |
|-----|------|---------|
| **淡入淡出** | 柔和过渡 | 时间跳转 |
| **切换** | 快速转场 | 对话场景 |
| **推进** | 进入细节 | 情绪升级 |
| **拉出** | 揭示全貌 | 场景展开 |

### 连贯控制技巧

**核心原则：关联性设计**

1. **视觉关联**：两镜之间有共同视觉元素
   ```
   镜1：特写手中的玉佩
   镜2：拉出到全身（玉佩在胸前）
   ```

2. **逻辑关联**：动作/事件连续
   ```
   镜1：推门进入
   镜2：已站在厅中央
   ```

3. **光线关联**：保持光源一致
   ```
   镜1：夕阳从左窗照入
   镜2：阴影方向相同
   ```

### 首尾帧补间（可灵AI）

**操作：**
1. 上传前后两个场景图
2. AI自动生成自然过渡
3. 适合场景切换（如室内→室外）

## ⚠️ 新手避坑指南

### 十大错误

| 错误 | 后果 | 解决 |
|-----|------|------|
| 工具贪多 | 效率低 | 每步只用1个工具 |
| 追求完美 | 无法完成 | 设"满意线"非"完美线" |
| 镜头太长 | 容易出错 | 单镜控制10-15秒 |
| 风格混用 | 视觉割裂 | 同一部视频用同一工具 |
| 忽略衔接 | 跳戏 | 注意首尾帧连贯 |
| 台词太文 | 出戏 | 用大白话 |
| 逻辑太多 | 无脑不够 | 冲突性 > 逻辑性 |
| 反派太弱 | 不够爽 | 反派要强，主角更强 |
| 没有钩子 | 不追剧 | 每集留悬念 |
| 不看数据 | 盲目制作 | 根据反馈迭代 |

### 建议

1. **先做1集跑通流程** > 做10集半成品
2. **用核心工具用熟** > 学一堆工具
3. **接受AI的"随机惊喜"** > 追求完美控制
4. **根据数据迭代** > 闭门造车
