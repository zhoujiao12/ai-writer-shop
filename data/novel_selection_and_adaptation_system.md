# 小说筛选与爆款改编操作系统

> 核心技能：选书依据 + 改编方法
> 用途：从海量小说中筛选爆款 + 将普通小说改造成爆款开头
> 版本：v1.0 实战执行版

---

## 🎯 第一部分：爆款小说筛选依据

### 一、硬性指标（一票否决）

#### 1. 平台门槛
| 平台 | 最低要求 | 爆款潜质 |
|------|----------|----------|
| 番茄 | ≥30万字 + ≥10万在读 | ≥50万字 + ≥30万在读 |
| 七猫 | ≥30万字 | ≥50万字 + 无砍文记录 |

#### 2. 排版检查
```
❌ 一票否决：
- 单段 > 500字
- 单章 > 3000字不分段
- 对话叙述混杂不分行
- 全篇无标点/格式混乱
```

#### 3. 节奏检查
```
❌ 直接淘汰：
- 前3页没有核心矛盾
- 金手指延迟超过1章
- 压制后7万字仍未收束
- 矛盾缓慢，全篇环境描写
```

---

### 二、核心筛选标准

#### 黄金公式
```
爆款 = 强矛盾 + 快金手指 + 完整情绪曲线 + 强代入感
```

#### 矛盾强度分级
| 等级 | 矛盾类型 | 案例 |
|------|----------|------|
| S级 | 生死存亡 | 被害死、全家灭门、末日求生 |
| A级 | 极端困境 | 饥荒、破产、被抛弃 |
| B级 | 身份落差 | 废物太子、穷小子被分手 |
| C级 | 日常纠纷 | 买菜被坑、同事矛盾 |

**选书原则**：矛盾强度 ≥ B级

#### 金手指时效
```
✅ 爆款：压制后立即出现（同一章内）
⚠️ 可用：压制后1章内出现
❌ 淘汰：压制后超过2章才出现
```

#### 情绪曲线完整性
```
完整曲线 = 压制 → 痛点 → 触发 → 反击 → 爽感释放

❌ 不完整案例：
- 有压制无反击 = 憋屈
- 有反击无压制 = 无感
- 有痛点无释放 = 断更预警
```

### 三、快速筛选检查清单

#### 第一轮：30秒快速判断
```
看标题：是否有具体数字/强烈反差/悬念钩子？
看开头：前3页是否有矛盾？
看排版：是否规范分段？
看平台：是否达到最低门槛？
```

#### 第二轮：3分钟深度判断
```
矛盾强度：是S/A/B级？
金手指：压制后多久出现？
情绪曲线：是否完整（压制→反击→爽）？
代入感：是否有普世痛点（背叛/欺压/失去）？
```

#### 第三轮：完整评估
```
起承转合是否完整？
爽点是否能一句话概括？
主角人设是否符合偏好（杀伐果断 > 圣母）？
是否有改编空间？
```

## 🔧 第二部分：小说改编爆款开头技能

### 一、提取核心元素

#### 步骤1：找到小说的"情绪核"
```
问自己三个问题：
1. 主角最大的痛苦是什么？
2. 主角最大的渴望是什么？
3. 最能引发读者情绪的场景是什么？

找到 = 情绪核
```

#### 步骤2：提炼三要素
```
【矛盾点】主角面临的核心困境
【痛点】读者最能共情的地方
【爆点】反转/金手指/爽感时刻
```

#### 步骤3：确定改编类型
根据小说特点选择开头类型：

| 小说特点 | 推荐开头类型 |
|----------|--------------|
| 身份差距大 | 身份反差型 |
| 重生/穿越 | 重生复仇型/极端困境型 |
| 有系统/金手指 | 系统觉醒型 |
| 情感纠葛强 | 情感背叛型 |
| 设定新奇 | 荒诞设定型 |

---

### 二、爆款开头改造方法

#### 方法1：数字冲击法
```
原小说：主角很穷，女友分手
↓ 改造
爆款开头："3年，100万，0。我打工供女友三年，花了100万，分手时她说了0个字。"
```

#### 方法2：身份反差法
```
原小说：主角是外卖员，很厉害
↓ 改造
爆款开头："送外卖的被嘲笑穷酸，特警冲进来：昨夜炸沉八百艘军舰。"
```

#### 方法3：极端困境法
```
原小说：主角穿越到饥荒年代
↓ 改造
爆款开头："重生到86年大雪封山，全家只剩3天口粮。父母把我分到柴屋，为一斤粮食逼我娶疯女人。"
```

#### 方法4：双循环改造法（核心）
```
原小说：主角获得系统，变强了
↓ 改造（添加第一轮失败）
爆款开头：
"我按传统方法修炼，结果被废物嘲笑。
就在我绝望时，激活了XX系统。
这次，我要让所有人闭嘴。"
```

#### 方法5：痛点前置法
```
原小说：主角慢慢发现女友出轨
↓ 改造（直接展示痛点）
爆款开头：
"供女友三年学费，毕业那天她说要分手。
转身看到她和富二代在一起。"
```

### 三、改编实战模板

#### 模板1：重生复仇类
```
前世[具体惨状] → 重生回[关键时刻] → 这一次[复仇宣言]

示例：
前世被妹妹害死，家产被夺。
重生回她陷害我的那天。
这一次，我要亲手送她下地狱。
```

#### 模板2：系统觉醒类
```
[具体困境] → [金手指出现] → [实力反转]

示例：
因穷被女友分手。
激活神豪系统获得十亿。
她跪求复合时，我已看她不上。
```

#### 模板3：身份反差类
```
所有人以为[表面身份] → 其实[真实身份] → 当[真相揭露]时

示例：
所有人都以为我是送外卖的。
其实我是首富公子。
当真相揭露那天，全村跪了。
```

#### 模板4：极端困境类
```
[极端困境] + [时间限制] → [生存威胁] → [反击开始]

示例：
重生回丧尸爆发前1小时。
前世被女友推进尸群。
这次，我要让她先体验绝望。
```

#### 模板5：双循环类（进阶）
```
【第一轮】[尝试] → [失败] → [绝望]
【触发】[意外事件] → [新机会]
【第二轮】[新方法] → [成功] → [打脸]

示例：
【第一轮】按规矩参加高考 → 落榜 → 被全村嘲笑
【触发】激活学霸系统
【第二轮】重新高考 → 省状元 → 全村闭嘴
```

### 四、改编核心原则

#### 原则1：删除无关内容
```
❌ 删：吃饭、睡觉、走路、无关对话
✅ 留：矛盾、冲突、金手指、爽点
```

#### 原则2：压缩铺垫
```
原文：主角花三章被欺负
改编：用2句话展示被欺负
"被嘲笑废物三年，今日我觉醒了系统。"
```

#### 原则3：强化冲突
```
原文：女友慢慢疏远
改编：直接展示背叛
"供她三年，毕业当天她上了别人的车。"
```

#### 原则4：制造悬念
```
结尾留钩子：
"当所有人都以为我要完蛋时，我却笑了。"
"下一秒，门被撞开。"
```

## 📋 第三部分：执行流程

### 完整操作流程

#### 步骤1：快速筛选（1分钟）
```
□ 标题是否有吸引力？
□ 平台指标是否达标？
□ 排版是否规范？
□ 前3页是否有矛盾？
```

#### 步骤2：深度评估（3分钟）
```
□ 矛盾强度分级（S/A/B/C）
□ 金手指时效检查
□ 情绪曲线是否完整
□ 代入感强度
```

#### 步骤3：提取核心（5分钟）
```
1. 找到情绪核（痛苦+渴望）
2. 提炼矛盾点、痛点、爆点
3. 确定改编类型
```

#### 步骤4：改编开头（10分钟）
```
1. 选择改编模板
2. 套用公式
3. 添加数字/反差/悬念
4. 使用转折衔接词
```

#### 步骤5：检查优化（2分钟）
```
□ 是否有情绪缺口？
□ 是否符合黄金3秒？
□ 是否使用了双循环？
□ 是否留了钩子？
```

## 🎯 实战案例

### 案例：普通小说改编

#### 原文
```
李明是一个普通的程序员，每天加班到很晚。他的女友小美觉得他没有前途，决定和他分手。李明很伤心，但还是接受了。后来他获得了一个系统，可以写代码赚钱。
```

#### 问题诊断
- 矛盾弱（只是分手）
- 没有具体数字
- 没有情绪缺口
- 金手指太慢

#### 改编后
```
【版本1：数字冲击型】
"5年，120万，1条短信。
我供女友读完研究生，花了120万。
毕业那天，她发了条短信：我们不合适。
正当我想跳楼时，系统激活了。"

【版本2：身份反差型】
"女友嫌我月薪3000，转身上了宝马。
她不知道，那辆宝马是我爸公司的。
系统激活后，我直接收购了宝马。"

【版本3：双循环型】
"我求她别走，她笑着说我废物。
绝望中，系统激活。
这一次，我要让她跪着求我。"
```
