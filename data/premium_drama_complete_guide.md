## 爆款公式

### 黄金3秒法则

> 短剧的黄金法则是"3秒留人"
> 必须用最炸裂的冲突、最颠覆的身份、最极致的情感

```
[身份错位] + [高冲突] = 瞬间抓住眼球
```

**示例：**
```
❌ 平淡：女主在府中散步
✅ 爆款：庶女被嫡姐当众羞辱，扒下外衣

❌ 平淡：王爷出门遇到女主
✅ 爆款：女主被推入池塘，王爷恰好路过
```

### 爆款三原则

| 原则 | 要求 |
|-----|------|
| **画面刺激** | 吻戏、冲突场面必须有 |
| **剧情无脑** | 冲突性 > 逻辑性 |
| **节奏爽快** | 每集都有卡点 |

### 情绪曲线公式

```
愤怒峰值 → 期待拐点 → 爽感高潮
（反派欺压）  （金手指）    （打脸复仇）
```

### 每集结构（60秒）

| 段落 | 时长 | 任务 |
|-----|------|------|
| 开头 | 0-10秒 | 钩子，抓住注意力 |
| 发展 | 10-40秒 | 情节推进 |
| 高潮 | 40-50秒 | 情绪爆点 |
| 结尾 | 50-60秒 | 悬念钩子 |

## 分镜设计

### 景别呼吸原则

```
远 → 中 → 近 → 特写 → 退回中/远
```

| 景别 | 用途 | 观众感受 |
|-----|------|---------|
| 远景 | 交代环境 | 疏离、宏观 |
| 全景 | 人物全身 | 完整、客观 |
| 中景 | 膝盖以上 | 平衡、参与 |
| 近景 | 腰部以上 | 亲近、交流 |
| 特写 | 局部细节 | 聚焦、紧张 |

### 分镜衔接检查表

**每两个相邻分镜之间检查：**

| 检查项 | 是否通过 |
|-------|---------|
| 人物位置是否合理延续？ | ✅/❌ |
| 动作是否衔接？ | ✅/❌ |
| 外貌/服装/饰品是否一致？ | ✅/❌ |
| 表情是否自然递进？ | ✅/❌ |
| 光线方向是否一致？ | ✅/❌ |

### 场景站位逻辑

**对话站位：**
```
    A君 ←────→ B君
    ↖视线        ↗视线
    
Camera: 在两人中间，侧45度
```

**视线逻辑：**
- A君说话时 → 看B君方向
- B君说话时 → 看A君方向

**禁忌：**
- ❌ 背对背说话
- ❌ 越轴（摄像机到关系线另一侧）
- ❌ 瞬移（没有移动过程）

## 台词写法

### 核心原则

> "角色用最简单的台词攻击对方，用最简单的手段打脸对方"

### 台词公式

| 场景 | 公式 | 示例 |
|-----|------|------|
| 打脸 | 简短有力 | "滚"、"你配吗" |
| 反击 | 直击要害 | "这就是你的底气？" |
| 复仇 | 冷静威慑 | "我会让你付出代价" |
| 撒娇 | 直接表达 | "抱抱"、"亲亲" |

### 禁止写法

```
❌ 太文艺： "我深感此番离去恐难再相见"
✅ 太白话： "这婚，我离了"

❌ 太含蓄： "或许我们可以..."
✅ 太直接： "闭嘴"

❌ 废话多： "我觉得可能大概你应该..."
✅ 简短：  "你给我等着"
```

## 衔接技巧

### 转场类型

| 类型 | 效果 | 适用场景 |
|-----|------|---------|
| 淡入淡出 | 柔和过渡 | 时间跳转 |
| 切换 | 快速转场 | 对话场景 |
| 推进 | 进入细节 | 情绪升级 |
| 拉出 | 揭示全貌 | 场景展开 |

### 连贯控制技巧

**视觉关联：** 两镜之间有共同视觉元素
```
镜1：特写手中的玉佩
镜2：拉出到全身（玉佩在胸前）
```

**逻辑关联：** 动作/事件连续
```
镜1：推门进入
镜2：已站在厅中央
```

**光线关联：** 保持光源一致
```
镜1：夕阳从左窗照入
镜2：阴影方向相同
```

## 人物一致性

### 一致性要素

| 要素 | 要求 |
|-----|------|
| 面部特征 | 同一人不能忽变 |
| 服装颜色 | 不能突然换色 |
| 发型 | 不能中途变发型 |
| 饰品 | 位置要一致 |
| 身高比例 | 要稳定 |

| 参考图锁定 | ZZD人物库 |
| R2V | 视频生成时保持一致 |

## 制作流程

### 极速流（1小时出片）

```
1. 剧本生成（10分钟）
2. 角色设计（10分钟）
3. 分镜图批量生成（15分钟）
4. 视频生成（20分钟）
5. 剪辑合成（5分钟）
```

### 精品流（1-3天）

```
Day 1: 剧本 + 角色设计
Day 2: 分镜设计 + 首尾帧
Day 3: 视频生成 + 配音
Day 4: 剪辑合成 + 发布
```

## 避坑指南

### 十大错误

| 错误 | 后果 | 解决 |
|-----|------|------|
| 工具贪多 | 效率低 | 每步只用1个工具 |
| 追求完美 | 无法完成 | 设"满意线"非"完美线" |
| 镜头太长 | 容易出错 | 单镜控制5-10秒 |
| 风格混用 | 视觉割裂 | 同一部视频用同一工具 |
| 忽略衔接 | 跳戏 | 注意首尾帧连贯 |
| 台词太文 | 出戏 | 用大白话 |
| 逻辑太多 | 无脑不够 | 冲突性 > 逻辑性 |
| 反派太弱 | 不够爽 | 反派要强，主角更强 |
| 没有钩子 | 不追剧 | 每集留悬念 |
| 不看数据 | 盲目制作 | 根据反馈迭代 |

### 建议

1. **先做1集跑通流程** > 做10集半成品
2. **用核心工具用熟** > 学一堆工具
3. **接受AI的"随机惊喜"** > 追求完美控制
4. **根据数据迭代** > 闭门造车
