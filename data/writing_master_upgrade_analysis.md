## 🔴 缺失模块（需要补充）

### 1. 节奏控制模块 ⭐⭐⭐ (高优先级)

**当前状态：** 情节设计中有提到，但没有独立模块

**需要补充的内容：**
- 场景节奏：长场景 vs 短场景的交替
- 句子层面的节奏控制（短句=快节奏，长句=慢节奏）
- 情感节拍的平衡（紧张场景后需要呼吸空间）
- 动作场景 vs 安静场景的交替规律
- 三种节奏类型：快节奏、慢节奏、混合节奏

**核心公式：**
```
快节奏 = 短句 + 动作 + 对话 + 冲突
慢节奏 = 长句 + 描写 + 内心独白 + 反思
```

---

### 2. 感官描写模块 ⭐⭐⭐ (高优先级)

**当前状态：** 情感描写中简单提到，缺乏系统整理

**需要补充的内容：**
- 五感细节：视觉、听觉、嗅觉、味觉、触觉的具体写法
- 感官约束技巧（限制一种感官来增强其他感官）
- 通感修辞（用一种感官描述另一种感官）
- 具体生动的描写方法（避免抽象词汇）

**核心原则：**
```
不要写"他很害怕"
要写"他的手掌心出汗，胃里像压着一块冰"
```

---

### 3. 场景构建模块 ⭐⭐⭐ (高优先级)

**当前状态：** 完全缺失

**需要补充的内容：**
- **Swain的场景-续篇结构（Scene-Sequel）：**
  - 场景 = 目标 + 冲突 + 灾难
  - 续篇 = 反应 + 困境 + 决定
- 场景三要素：地点 + 人物 + 动作
- 场景的开头和结尾技巧
- 场景之间的衔接方法
- 每个场景必须有冲突

**核心公式：**
```
场景（推动情节）：目标 → 冲突 → 灾难
续篇（处理反应）：反应 → 困境 → 决定
```

---

### 4. 叙事视角模块 ⭐⭐ (中优先级)

**当前状态：** 完全缺失

**需要补充的内容：**
- 第一人称：优点（亲密感）和局限（视角受限）
- 第三人称有限：最常用，聚焦单一角色
- 第三人称全知：上帝视角，可进入所有角色内心
- 第三人称客观：只观察，不进入内心
- 第二人称：实验性写法
- 视角切换的规则（每场景/每章节一个视角）
- 避免"视角跳跃"（head-hopping）

**核心规则：**
```
每场景只能有一个视角角色
切换视角 = 新场景或新章节
```

### 5. 修改编辑模块 ⭐⭐ (中优先级)

**当前状态：** 完全缺失

**需要补充的内容：**
- 三层修订法：
  - 故事层：结构、情节、角色弧光
  - 场景层：每个场景的功能和节奏
  - 句子层：语言、对话、描写
- 自我编辑检查清单
- 常见问题修复：
  - 被动语态消除
  - 填充词删除
  - 冗余形容词删减
  - "说"的变体替换

**核心原则：**
```
写作 = 创造（不自我审查）
编辑 = 删减（无情删减）
两次编辑法：结构编辑 → 文字编辑
```

### 6. 写作障碍克服模块 ⭐ (低优先级)

**当前状态：** 完全缺失

**需要补充的内容：**
- 写作障碍的6大原因：
  - 完美主义
  - 害怕失败
  - 缺乏灵感
  - 疲劳
  - 方向不清
  - 过度自我批评
- 克服方法：
  - 自由写作（Free Writing）
  - 改变环境
  - 设定小目标
  - 允许烂初稿
  - 写作伙伴/社群
- 建立写作习惯：
  - 固定时间
  - 固定地点
  - 仪式感

**当前状态：** 对话写作中有潜台词，但不系统

**需要补充的内容：**

  - 隐喻、明喻、拟人、夸张
  - 象征、反讽、伏笔
  - 通感、典故、双关
- 潜台词写作：
  - 角色说的 ≠ 角色想的

**核心原则：**
```
好的象征是读者自己发现的
故事应该在不发现象征的情况下也能成立
```
