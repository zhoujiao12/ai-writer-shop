# 小说数据库系统 - 使用指南

## 📚 系统概述

这是一个完整的小说数据库系统，用于：
- 爬取番茄、七猫等平台的排行榜数据
- 分析成功小说的模式和规律
- 建立检索系统，随时查询
- 监控趋势变化，发现新机会

## 📊 功能模块

### 模块1：数据库管理

```python
from novel_database_system import NovelDatabase

db = NovelDatabase()

# 添加书籍
book_data = {
    "title": "重生之都市仙尊",
    "author": "七月雪",
    "platform": "番茄",
    "genre": "都市修仙",
    "word_count": 3500000,
    "read_count": 50000000,
    "rating": 9.2,
    "ranking": 1,
    "opening_pattern": "重生复仇型",
    "conflict_type": "S级-生死存亡",
    "opening_text": "前世，他被...",
}
db.add_book(book_data)

# 搜索书籍
results = db.search(query="重生", genre="都市修仙", min_rating=8.0)

# 获取统计
stats = db.get_stats()
```

### 模块2：分析系统

```python
from novel_database_system import NovelAnalyzer

analyzer = NovelAnalyzer(db)

# 分析开头模式
opening_patterns = analyzer.analyze_opening_patterns()

# 分析矛盾类型
conflict_types = analyzer.analyze_conflict_types()

# 分析题材趋势
genre_trends = analyzer.analyze_genre_trends()

# 找到成功公式
formulas = analyzer.find_successful_formulas()

# 生成完整报告
report = analyzer.generate_report()
```

### 模块3：检索系统

```python
from novel_database_system import NovelRetriever

retriever = NovelRetriever(db)

# 找到类似开头
similar = retriever.find_similar_openings("重生复仇，家破人亡")

# 推荐成功公式
recommendation = retriever.recommend_formula("玄幻", "男频")
```

### 模块4：趋势监控

```python
from novel_trend_monitor import TrendMonitor

monitor = TrendMonitor()

# 记录每日快照
monitor.record_snapshot(books, platform="番茄", date="2026-03-27")

# 获取趋势报告
trends = monitor.get_trend_report(days=7)

# 保存报告
monitor.save_trend_report(trends)
```
