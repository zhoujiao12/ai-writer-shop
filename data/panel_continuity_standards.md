# 分镜连贯性标准 v1.0

> 上下分镜必须无缝衔接，不能"跳戏"
> 更新时间：2026-03-31

---

## 🎯 连贯性五大要素

### 1. 空间连贯

**原则：** 上一镜在左，下一镜不能突然在右

**示例：**
```
❌ 错误：
镜1：苏婉音站在池塘左侧
镜2：苏婉音突然出现在池塘右侧

✅ 正确：
镜1：苏婉音站在池塘左侧，被拖向池塘
镜2：苏婉音从左侧落入池塘（位置延续）
```

**检查方法：**
- 画一张场景平面图
- 标记每镜人物位置
- 确保位置合理移动

---

### 2. 动作连贯

**原则：** 上一镜的动作，下一镜要延续

**示例：**
```
❌ 错误：
镜1：苏婉音被推入池塘
镜2：苏婉音站在岸上（动作断裂）

✅ 正确：
镜1：苏婉音被推入池塘，身体前倾
镜2：苏婉音落水，水花四溅（动作延续）
镜3：苏婉音在水中挣扎（动作延续）
```

**动作衔接表：**
| 上一镜动作 | 下一镜动作 |
|-----------|-----------|
| 被推 | 落下 |
| 举起手 | 手放下 |
| 张嘴 | 说话/喊叫 |
| 看向左边 | 左边出现东西 |
| 转身 | 面对新方向 |

---

### 3. 人物连贯

**原则：** 同一人物外貌、服装、特征必须一致

**关键点：**
```
✅ 必须一致：
- 发型
- 服装颜色/款式
- 特征痣/疤痕
- 饰品（耳环、发簪）
- 年龄感

⚠️ 容易出错：
- 发丝方向
- 衣服褶皱
- 首饰位置
- 妆容浓淡
```

**解决方案：**
1. **先生成角色参考图**
2. **上传到ZZDH人物库**
3. **每次生图都引用参考图**
4. **使用Vidu R2V保持一致性**

---

### 4. 情绪连贯

**原则：** 表情要自然过渡，不能突变

**示例：**
```
❌ 错误：
镜1：苏婉音平静
镜2：苏婉音大哭（情绪跳跃）

✅ 正确：
镜1：苏婉音眼眶含泪
镜2：泪水滑落
镜3：掩面哭泣（情绪递进）
```

**情绪递进公式：**
```
平静 → 惊讶 → 愤怒 → 爆发
或
开心 → 疑惑 → 担忧 → 恐惧
```

---

### 5. 光线连贯

**原则：** 同一场景光线方向要一致

**示例：**
```
❌ 错误：
镜1：夕阳从左侧照来（左脸亮）
镜2：夕阳从右侧照来（右脸亮）

✅ 正确：
镜1：夕阳从左侧照来（左脸亮）
镜2：夕阳继续从左侧照来（左脸亮）
```

**提示词技巧：**
```
在每镜提示词中写明：
"golden hour lighting from left side"
```

## 🛠️ 实操技巧

### 技巧1：分镜脚本标注

**在每镜标注：**
```
【场景1】池塘边 · 黄昏
位置：池塘西侧
光线：夕阳从左侧照来
动作：被拖向池塘
情绪：恐惧+挣扎

【场景2】池塘中
位置：池塘中央（从西侧落入）
光线：夕阳从左侧照来（延续）
动作：落水+挣扎
情绪：恐惧+绝望
```

### 技巧2：参考图锁定

**ZZDH操作：**
1. 生成第一镜满意的图片
2. 将第一镜图片作为第二镜的参考图
3. 提示词中强调"same character"
4. 保持人物一致性

### 技巧3：提示词继承

**在视频提示词中加入：**
```
"Seamlessly continuing from previous shot"
"Same character, same outfit, same location"
"Maintain exact character consistency"
```

### 技巧4：首尾帧控制

**使用首尾帧生视频：**
```
镜1：首帧=镜1图片，尾帧=镜2图片
镜2：首帧=镜2图片，尾帧=镜3图片
```
这样可以确保两镜之间自然过渡。

## 🚫 常见错误

| 错误 | 表现 | 解决 |
|-----|------|------|
| **跳切** | 场景突然变化 | 加入过渡镜 |
| **穿帮** | 服装/发型突变 | 用参考图 |
| **光线跳** | 光源方向变化 | 提示词标注光源 |
| **情绪跳** | 表情突变 | 加中间状态 |
| **位置跳** | 人物瞬移 | 画平面图 |

## ✅ 连贯性验证流程

**生成后必须检查：**

1. **单镜检查**
   - 人物外貌是否一致
   - 服装是否相同
   - 饰品是否对齐

2. **双镜对比**
   - 位置是否延续
   - 动作是否衔接
   - 情绪是否自然

3. **全片预览**
   - 整体是否流畅
   - 有无明显跳戏
   - 情绪曲线是否完整
