## 二、核心技术特性

### 🔧 1. 创新混合架构

```
Gated Delta Networks + Sparse MoE

原理：
• 不是所有参数同时工作
• 每次推理只激活2-3B参数
• 针对特定任务选对"专家"
• 效果不差于全量激活的30B模型

类比：
就像一个团队里有9个专家，每次只派最合适的2-3个上场
比派一个啥都会但哪个都不精通的120人大团队更高效
```

---

### 🧠 2. 推理时计算（Test-Time Compute）

```
模型在回答时会"多想几步"
通过内部推理链提升答案质量
让小模型在逻辑推理和数学题上的表现大幅提升
不再只靠参数记忆
```

---

### 🎨 3. 原生多模态统一

```
早期融合（Early Fusion）：
• 在预训练阶段就将文本、图像、视频Token深度融合
• 不同于传统通过适配器连接视觉模块的做法

能力覆盖：
✅ OCR（光学字符识别）
✅ 空间推理
✅ 文档理解
✅ 长视频时序建模
```

---

### 🎓 4. 大规模强化学习训练

```
训练方式：
• 在数百万个Agent环境中进行大规模RL训练
• 显著增强了逻辑推理、数学解题、代码生成的稳定性

效果：
✅ 降低幻觉（减少事实性错误）
✅ 逻辑一致性校验
✅ 执行复杂系统指令更可靠
```

### 🎯 适用场景

#### ✅ 适合本地替代云端

```
• 代码补全与调试：高频、数据敏感、要求低延迟
• 结构化数据处理：JSON解析、格式转换、数据清洗
• 本地文档问答：不想把内部文档发到云端
• 数学计算与推理：这是9B的强项之一
• 批量文本分类/摘要：高吞吐场景，成本优势明显
```

#### ❌ 仍需云端大模型

```
• 超长文档分析（Claude有200K上下文）
• 复杂多轮创作（写作质量有差距）
• 图像理解（需要另外部署VLM）
• 需要最新信息（本地模型有知识截止日期）
```

## 四、硬件要求

### 💻 推荐配置

| 配置级别 | 硬件要求 | 推荐模型 | 性能 |
|---------|---------|---------|------|
| **最低** | 16GB内存 + 集成显卡 | Q3_K_S量化 | CPU推理，较慢 |
| **入门** | 16GB内存 + 8GB显存 | Q4_K_M量化 | 流畅运行 |
| **推荐** | RTX 3060 12G | INT4量化 | 甜点级，6-7GB显存 |
| **最佳** | RTX 4080/4090 24GB | FP16原生精度 | 全功能体验 |

### 🎮 实测案例

#### RTX 3060 12G 运行情况

```
✅ INT4量化版本
✅ 显存占用：约 6-7GB
✅ 剩余显存：可支持 16K-32K 上下文
✅ 推理速度：流畅，无卡顿
✅ 可同时运行其他应用（微信等）
```

#### RTX 3060 Ti / 4060 8G 运行情况

```
✅ Q3_K_S量化版本
✅ 显存占用：约 6GB
✅ 上下文建议：8K-16K（不要勉强开32K）
⚠️ 关闭视觉加速（MMPROJ_OFFLOAD=off）
⚠️ 显存有限，容易溢出导致黑屏
```

