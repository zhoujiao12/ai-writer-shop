## 🎯 核心公式

### 一、爆款开头公式
```
数字冲击 + 情绪缺口 + 第一轮失败 + 触发反转 + 最终成功
```

### 二、双循环故事公式（PAR-TAR）
```
Problem → Action → Result → Trigger → Action → Result
   ↓         ↓        ↓        ↓         ↓        ↓
  问题     错误行动   失败     触发事件   正确行动   成功
```

### 三、黄金3秒公式
```
第1秒：视觉冲击（数字/反差/关键词）
第2秒：情绪钩子（背叛/欺压/困境）
第3秒：悬念留白（接下来会怎样？）
```

## 🔑 核心洞察

### 洞察1：完整 ≠ 精彩
> "Complete is not the same as compelling."
> 单循环故事"完成"了，但读者已经走完了。

### 洞察2：失败比成功更吸引人
> 第一轮失败制造悬念，第二轮成功释放情绪。

### 洞察3：标题决定80%
> "Mediocre articles with great titles outperform excellent articles with bland titles by 10x"

### 洞察4：痛点是核心
> 所有爆款都在戳痛点：背叛之痛、欺压之痛、失去之痛。

### 洞察5：爽点 = 正义迟到但到了
> 观众想看的不是变强，而是变强后的反击。

## 📋 实战检查清单

### 选书检查
```
□ 前3页是否有核心矛盾？
□ 金手指是否在压制后快速出现？
□ 情绪曲线是否完整？
□ 排版是否规范？
□ 是否符合审核要求？
□ 爽点是否能一句话概括？
□ 是否有强烈代入感？
□ 平台指标是否达标？
```

### 开头检查
```
□ 是否在3秒内建立情绪缺口？
□ 是否有具体数字/时间/地点？
□ 是否制造了好奇心缺口？
□ 是否避免了"介绍性"废话？
□ 标题是否传达了明确利益点？
```

### 结构检查
```
□ 是否使用了双循环（PAR-TAR）？
□ 第一轮是否有失败/挫折？
□ 是否有触发事件推动第二轮？
□ 张力是否持续到最后一刻？
□ 转折衔接是否自然？
```
