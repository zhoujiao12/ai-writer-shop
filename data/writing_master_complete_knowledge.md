## 第一部分：故事结构核心体系

### 一、三幕结构（Three-Act Structure）

**核心公式：**
```
Act 1（铺垫）→ Act 2（冲突）→ Act 3（解决）
```

**详细分解：**

| 幕 | 内容 | 占比 | 核心任务 |
|---|------|------|---------|
| **Act 1** | 铺垫（Setup） | 25% | 介绍人物、世界观、引发事件 |
| **Act 2** | 冲突（Confrontation） | 50% | 障碍、考验、中点转折 |
| **Act 3** | 解决（Resolution） | 25% | 高潮、结局、新平衡 |

**Act 1 要素：**
- **Stasis（静态）**：主角的日常生活
- **Inciting Incident（引发事件）**：打破平衡的事件
- **First Turning Point（第一转折点）**：主角决定踏上旅程

**Act 2 要素：**
- **Rising Action（上升动作）**：一系列障碍和考验
- **Midpoint（中点）**：故事的中间转折
- **Second Turning Point（第二转折点）**：危机加深

**Act 3 要素：**
- **Climax（高潮）**：最终对决
- **Resolution（解决）**：新平衡建立

---

### 二、英雄之旅（Hero's Journey）

**约瑟夫·坎贝尔的12阶段：**

```
第一幕：启程
├── 1. 普通世界（Ordinary World）
├── 2. 冒险召唤（Call to Adventure）
├── 3. 拒绝召唤（Refusal of the Call）
├── 4. 遇见导师（Meeting with the Mentor）
└── 5. 跨越门槛（Crossing the Threshold）

第二幕：启蒙
├── 6. 考验、盟友、敌人（Tests, Allies, Enemies）
├── 7. 接近洞穴（Approach to the Inmost Cave）
├── 8. 磨难（Ordeal）
└── 9. 奖赏（Reward）

第三幕：归来
├── 10. 返回之路（The Road Back）
├── 11. 复活（Resurrection）
└── 12. 携万灵药归来（Return with the Elixir）
```

**核心原则：**
- 主角从"普通人"变成"英雄"
- 必须经历"死亡"与"重生"
- 带回改变世界的"宝物"（知识/力量/爱）

---

### 三、七点故事结构（7-Point Story Structure）

**丹·威尔斯提出：**

```
1. Hook（钩子）→ 2. Plot Turn 1（转折1）→ 3. Pinch 1（挤压1）
→ 4. Midpoint（中点）→ 5. Pinch 2（挤压2）→ 6. Plot Turn 2（转折2）
→ 7. Resolution（解决）
```

**写作建议：从结局倒推！**
- 先写Resolution
- 再写Hook
- 然后填充中间

---

### 四、五幕结构（Five-Act Structure）

**莎士比亚式结构：**

| 幕 | 内容 | 功能 |
|---|------|------|
| **Act 1** | 铺垫（Exposition） | 介绍人物和背景 |
| **Act 2** | 上升动作（Rising Action） | 冲突开始 |
| **Act 3** | 高潮（Climax） | 矛盾最激烈 |
| **Act 4** | 下降动作（Falling Action） | 后果显现 |
| **Act 5** | 灾难/解决（Catastrophe/Denouement） | 最终结局 |

## 第二部分：角色塑造核心体系

### 一、角色弧光（Character Arc）

**四种基本弧光类型：**

| 类型 | 起点 | 终点 | 适用作品 |
|------|------|------|---------|
| **正向弧光** | 有缺陷 | 克服缺陷 | 英雄故事、成长小说 |
| **负向弧光** | 有希望 | 堕落 | 悲剧、黑色电影 |
| **平坦弧光** | 坚守信念 | 改变世界 | 夏洛克·福尔摩斯 |
| **腐败弧光** | 有真理 | 选择谎言 | 反英雄故事 |

**角色弧光三阶段：**
```
Starting Line（起点）→ Messy Middle（中间过程）→ Finish Line（终点）
```

**核心要素：**
- **Lie（谎言）**：角色相信的错误信念
- **Truth（真理）**：角色需要学习的真理
- **Flaw（缺陷）**：阻碍角色的弱点
- **Ghost（幽灵）**：过去的创伤

---

### 二、角色开发六步法

**凯伦·罗斯的方法：**

```
1. HERO（主角）- 外貌、背景
2. HEROINE（女主角）- 或第二主角
3. VILLAIN（反派）- 或对立力量
4. JOB（工作）- 职业如何带入故事
5. DEFINING EVENTS（定义性事件）- 塑造角色的事件
6. MOTIVATION（动机）- 为什么这么做
```

**角色设定的关键问题：**
- 他们最渴望什么？
- 他们最恐惧什么？
- 他们相信的"谎言"是什么？
- 他们的"幽灵"（过去创伤）是什么？

---

### 三、角色塑造的反差技巧

**核心原则：用反差让角色立体**

| 技巧 | 示例 |
|-----|------|
| **外表 vs 内在** | 优雅老太太，爱戴假胡子唱老生 |
| **公众形象 vs 私下自我** | 叛逆少女，每晚看妈妈的错题本 |
| **言语 vs 行动** | 嘴硬心软 |
| **期待 vs 现实** | 被认为不学无术，实际每晚苦读 |

## 第三部分：情节设计核心体系

### 一、冲突设计五维度

**核心公式：**
```
对比 → 反差 → 冲突 → 转折 → 和解
```

**冲突类型：**

| 类型 | 内容 | 示例 |
|------|------|------|
| **人物 vs 人物** | 两个人物之间的对抗 | 主角 vs 反派 |
| **人物 vs 自然** | 与自然环境的斗争 | 《老人与海》 |
| **人物 vs 社会** | 与社会制度的冲突 | 《1984》 |
| **人物 vs 自我** | 内心矛盾和挣扎 | 《哈姆雷特》 |
| **人物 vs 科技** | 与技术/命运的对抗 | 科幻小说 |

**冲突设计原则：**
- 每一场戏都要有冲突
- 冲突要有层次（外层→内层）
- 冲突要不断升级

---

### 二、反转技巧（Plot Twist）

**八种经典反转类型：**

| 类型 | 说明 | 经典案例 |
|------|------|---------|
| **身份反转** | 角色身份的惊人真相 | 《星球大战》：我是你父亲 |
| **不可靠叙述者** | 叙述者在撒谎或精神不稳定 | 《禁闭岛》 |
| **时间线反转** | 故事发生在不同时间 | 《记忆碎片》 |
| **视角反转** | 改变理解故事的视角 | 《消失的爱人》 |
| **动机反转** | 角色动机与预期相反 | 《第六感》 |
| **因果关系反转** | 结果实际上是原因 | 《云图》 |
| **同一人物反转** | 两个角色是同一个人 | 《搏击俱乐部》 |
| **死人反转** | 已知死去的角色其实活着 | 《一般嫌疑人》 |

**反转设计原则：**
- 必须在后半部分合理铺垫
- 回看时"原来如此"
- 不要为了反转而反转

### 三、悬念设计技巧

**三大技巧：**

1. **信息不对称**：读者知道角色不知道的
2. **时间压力**：倒计时制造紧迫感
3. **多线叙事**：交替切换制造悬念

- 多重视角

- 伪造的死亡

## 第五部分：对话写作核心体系

### 一、大卫·马梅特对话九法则

**核心原则：**

1. **明确剧本类型**：银幕 vs 舞台会改变对话方式
2. **感受节奏**：听真实人说话的节奏
3. **潜台词为王**：说的和想的要不同
4. **少即是多**：删除不必要的词
5. **每句有目的**：推进情节或展示人物
6. **避免解释**：不要让角色说明显而易见的事
7. **打断是真实的**：真实对话充满打断
8. **沉默是金**：有时不说比说更有力
9. **每个角色有独特声音**：不同角色说话方式不同

---

### 二、亚伦·索尔金对话技巧

**核心特点：**
- 快节奏、高密度
- 行走对话（walk and talk）
- 潜台词丰富
- 专业术语增强真实感

**写作建议：**
- 朗读对话测试流畅度
- 删除所有不必要的"你好""再见"
- 每句对话要推进情节

---

### 三、对话四要素

```
1. 推进情节（Advance Plot）
2. 揭示人物（Reveal Character）
3. 提供信息（Provide Exposition）
4. 制造冲突（Create Conflict）
```

**原则：每句对话至少满足一个要素**

## 第六部分：情感描写核心体系

### 一、情感描写七大方法

| 方法 | 说明 | 示例 |
|------|------|------|
| **直白式** | 直接描述心理活动 | "她感到无比悲伤。" |
| **内心独白** | 角色自言自语 | （心理活动的直接呈现） |
| **情绪直感** | 描述身体感受 | "心冷得紧缩起来。" |
| **梦境幻觉** | 通过梦境表现内心 | 凡卡的梦、卖火柴的小女孩 |
| **表情描写** | 通过表情暗示情绪 | 脸色苍白、发青 |
| **动作描写** | 通过动作表现情绪 | 排出九文大钱 vs 扔在柜上 |
| **景物衬托** | 以景写情 | 惨淡的光芒照射着雪地上的血迹 |

---

### 二、"Show, Don't Tell"四层次

**层次一：命名情感（最"Tell"）**
```
"他很生气。" → 最简单，但不生动
```

**层次二：使用"说"的变体**
```
"他愤怒地说。" → 仍然是"Tell"
```

**层次三：描述身体反应**
```
"他心跳加速，双手握拳。" → 开始"Show"
```

**层次四：展示外部行动（最"Show"）**
```
"他把杯子摔在地上，摔门而去。" → 最生动
```

**建议：主要使用层次四，层次三用于强烈情感**

---

### 三、情感渲染三阶段

```
起始情绪 → 发展过程 → 最终情绪
```

**示例：**
```
"走進教室前，我滿心期待。考卷一發下來，我愣住了，題目比預想的難太多。交卷時，我只剩下自責與一種說不出口的沮喪。"

期待 → 震驚 → 自責/沮喪
```

**技巧：列出情绪变化的三种状态，让文字有层次**

### 二、微短剧剧本创作要点

**核心特点：**
- 1-2分钟一集，500字左右
- 60-90秒一个爆点或亮点
- 人物集中，主线清晰
- 矛盾冲突要强

**写作原则：**
1. **不要心理描写** - 转化为台词、动作、表情
2. **镜头描写具体明确** - 不要用模糊词
3. **台词简短有力** - 超过60秒视频文字不超过180字
4. **每集有起承转合** - 有矛盾冲突

## 第十部分：场景构建核心体系

### 一、Scene-Sequel 结构（Dwight Swain 核心）

**场景（Scene）= 目标 + 冲突 + 灾难**
- Goal：角色在这个场景想要什么
- Conflict：什么阻止角色达成目标
- Disaster：角色没得到想要的，反而更糟

**续篇（Sequel）= 反应 + 困境 + 决定**
- Reaction：角色对灾难的情感和身体反应
- Dilemma：角色面临的困境和选择
- Decision：角色做出新决定

### 二、完整循环
```
Goal → Conflict → Disaster → Reaction → Dilemma → Decision → 新Goal
场景                     续篇                          场景
```

**详细内容见：** `writing_master_module_scene.md`
