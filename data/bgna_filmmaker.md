# 《本宫按律办事》Vidu专业分镜脚本

## P1：公主登场

**场次**：公主府正殿·日
**景别**：远景→全身→面部特写
**镜头运动**：固定机位，公主由远及近走来，镜头不动，人物移动
**场景描述**：
```
正殿金色穹顶高耸，九根红色立柱矗立两侧。
金色阳光从殿顶镂空处倾泻而下，形成神圣光柱。
地面铺着黑色大理石，倒映公主身影。
两名身披铠甲的侍卫分列殿门两侧，手持长枪，一动不动如同雕塑。
殿内寂静无声，只有公主凤冠上的流苏发出细微碰撞声。
```

**人物动作**：
```
【公主赵鸾】
头戴九凤金冠，冠顶羽毛在光柱中微微颤动。
身穿金红色凤冠霞帔，裙摆拖地，每一步都留下金色涟漪。
面容绝美却毫无表情，眼神如古井死水。
步伐沉稳均匀，每步间距精确相等，如同踩在无形的刻度上。
双手自然垂于身侧，拇指佩戴一枚金龙扳指。
不怒自威，压迫感让空气都凝固了。
```

**对白/台词**：无（口型同步用）

**情绪氛围**：威严、压迫、冷漠、令人窒息

**首帧**：殿门外，一个金色光点，由远及近
**尾帧**：公主停在殿中央，凤冠特写，光芒笼罩全身
**时长**：6秒

## P2：红袖戴冠挑衅

**场次**：偏殿内室·日
**景别**：中景→特写（镜子反射）
**镜头运动**：固定机位，镜头不动，演员在画面中表演
**场景描述**：
```
偏殿内室不大，四面悬挂着褐色帷幔。
一面巨大的古铜镜立在中央，镜框雕刻龙凤呈祥。
镜前摆着一张小几，几上放着一顶金色凤冠。
凤冠做工精细，九只金凤盘旋，镶嵌红宝石。
室内只有一盏油灯，火焰摇曳，影子在墙上晃动。
```

**人物动作**：
```
【红袖（布衣女子）】
粗布衣裳与凤冠形成强烈反差。
她颤抖着双手拿起凤冠，缓缓戴在自己头上。
凤冠太大，歪歪斜斜地滑落到眉毛上。
她对着铜镜歪头打量，嘴角慢慢扬起一个得意的弧度。
"这凤冠我戴着，是不是也挺像那么回事？"
她轻声自语，声音里带着三分得意七分紧张。
手指不自觉地抚摸着凤冠上的珍珠，眼眶微红。
```

**对白/台词**：「这凤冠我戴着，是不是也挺像那么回事？」

**情绪氛围**：紧张、挑衅、命运倒计时、黑色幽默

**首帧**：铜镜前，凤冠在小几上静止
**尾帧**：镜中女子歪戴凤冠得意表情特写
**时长**：5秒

## P3：驸马帮腔

**场次**：偏殿门口·日
**景别**：双人镜头（过肩）
**镜头运动**：缓慢推进，从全景到中景
**场景描述**：
```
偏殿门口连接正殿，两名女子一前一后。
前方女子（红袖）还戴着那顶不合身份的凤冠，
身体僵硬地站在原地，不敢动弹。
后方驸马刘云快步上前，满脸焦急。
他张开双臂挡在红袖身前，像一只护崽的老母鸡。
额头上渗出细密的汗珠，儒雅的面孔涨得通红。
```

**人物动作**：
```
【驸马刘云】
一身洁白书生袍，腰系玉佩，风度翩翩。
此刻却狼狈不堪，袍角还沾着灰尘。
他跨步挡在红袖身前，展开双臂形成保护姿态。
声音因紧张而微微发颤：
"鸾儿，红袖就是开个玩笑，你别当真。"
他回头看了红袖一眼，眼神里满是心疼与哀求。
再转向公主时，嘴唇哆嗦，双手合十近乎哀求。
```

**对白/台词**：「鸾儿，红袖就是开个玩笑，你别当真。」

**情绪氛围**：紧张、保护、爱莫能助、可怜

**首帧**：偏殿内，红袖戴冠站立
**尾帧**：驸马张开双臂护在红袖身前
**时长**：6秒

## P4：公主下令【核心高潮】

**场次**：正殿中央·日
**景别**：特写→面部特写
**镜头运动**：快推，从全身推到面部
**场景描述**：
```
正殿中央，公主站在最高处。
黑色大理石地面倒映她金色的身影。
九名侍卫分成两列，单膝跪地等待命令。
公主右手缓缓抬起，掌心托着一枚金色令牌。
令牌上雕刻着五爪金龙，在光芒中仿佛要破壁而出。
殿内温度骤降，空气凝固成冰。
```

**人物动作**：
```
【公主赵鸾】
眼睑低垂，睫毛在颧骨上投下阴影。
眼神扫过全场，像刀一样划过每个人的脸。
每一侍卫都与她目光相接，无人敢抬头。
她开口，声音不大，却清晰传到每个人耳中：
"有人自比公主，意图谋朝篡位。"
停顿一拍，嘴角微微下撇。
"九族一个不留。"
语气平淡，像在讨论今日天气。
```

**对白/台词**：「有人自比公主，意图谋朝篡位。九族一个留着。」

**情绪氛围**：冰冷、威严、宣判、死亡

**首帧**：殿内全景，驸马在前公主在后
**尾帧**：公主手举令牌特写，光芒笼罩
**时长**：8秒

## P5：金吾卫破窗

**场次**：正殿外→内·日
**景别**：全景→特写
**镜头运动**：360度环绕，从窗外向内拍
**场景描述**：
```
突然，殿外传来整齐的脚步声。
轰隆！轰隆！轰隆！
十二名金吾卫同时踹破十二扇窗户涌入。
他们全身黑色精铁铠甲，手持战斧，面罩遮住口鼻。
唯有一双双眼睛露出，寒光闪闪，如同地狱来的使者。
玻璃碎片在空中飞舞，在阳光下折射出刺眼的光芒。
每个侍卫的动作完全同步，如同一人。
```

**人物动作**：
```
【金吾卫】
十二人分成四组，从东、西、北三面破窗。
南面留给公主，堵死所有退路。
为首队长一声令下：
"拿下！"
十二把战斧同时举起，寒光闪烁。
他们行动如同一人，整齐划一，没有一丝声音。
```

**对白/台词**：无（行动场景）

**情绪氛围**：震撼、压迫、正义降临、暴力美学

**首帧**：殿内，公主举令牌
**尾帧**：金吾卫破窗而入，包围全场
**时长**：6秒

驸马看着红袖被按倒在地，理智崩溃。

他满脸通红，青筋从额头一直蔓延到脖颈。
双眼充血，像一头发疯的野兽。
公主站在原地，居高临下地俯视着他。
眼神里没有愤怒，只有冷漠的审视。
```

**人物动作**：
```
【驸马刘云】
他被侍卫架住双臂，双脚在地上拖出两道痕迹。
"这是公主府！你凭什么抓人？！"
他声嘶力竭，声音都劈了。
泪水从眼角滑落，滴在洁白书生袍上。
他拼命挣扎，却如同蜉蝣撼树。
整个人从愤怒变成绝望，再变成崩溃。
```

**对白/台词**：「这是公主府！你凭什么抓人？！」

**情绪氛围**：愤怒、绝望、崩溃、对比

**首帧**：红袖被按倒地
**尾帧**：驸马崩溃vs公主冷漠对峙

## P8：公主引用律法【核心爽点】

**场次**：正殿中央·日
**景别**：特写（面部+手部）
**镜头运动**：固定长镜头，保持特写
**场景描述**：
```
殿内寂静，只有公主的声音回荡。
她一字一顿，每个字都像刀子刻进石头。
公主面前摊开一本金色封面的律法典籍。
她修长的手指点在一行字上。
金色令牌静静躺在律法典籍旁。
殿内所有人屏住呼吸，等待宣判。
```

**人物动作**：
```
【公主赵鸾】
她走近一步，声音清冷如冰：
"凡庶民私服御用之物，斩。"
再近一步：
"凡僭越皇室之仪，凌迟。"
她俯视红袖，眼神如同看一只蝼蚁。
嘴角微微上扬，露出一个冰冷的弧度。
不是在笑，是在确认判决。
```

**对白/台词**：「凡庶民私服御用之物，斩。凡僭越皇室之仪，凌迟。」

**情绪氛围**：冷静、权威、智慧碾压、法律武器

公主转身，迈着不紧不慢的步伐离开。

身后，驸马瘫坐在地，仰望着她离开的背影。
铜镜反射出他狼狈的身影，衣衫不整，面如死灰。
一内一外，一胜一败，形成鲜明对比。
```

**人物动作**：
```
【公主赵鸾】
裙摆拖地，每一步都从容不迫。
凤冠上的流苏轻轻摇曳，发出细微声响。
她没有回头，甚至没有多看驸马一眼。
仿佛身后只是一片空气。
```

**对白/台词**：无

**情绪氛围**：完胜、对比、因果、史诗感

**首帧**：红袖被拖走

**时长**：8秒

## 格式说明

每个分镜包含：
1. **场次**：地点+时间
2. **景别**：用什么镜头
3. **镜头运动**：怎么动
4. **场景描述**：具体环境
5. **人物动作**：角色分解动作
6. **对白/台词**：需要口型同步的台词
7. **情绪氛围**：整体感觉
8. **首帧/尾帧**：Vidu首尾帧控制
9. **时长**：秒数
