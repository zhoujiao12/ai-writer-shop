## 三、关键技术要点

### 3.1 角色一致性（核心痛点）

**解决方案：**
- 使用"角色库"功能，上传多角度参考图
- 锁定种子值（Seed）
- 创建角色三视图

**效果：**
- 优质工具可达95%相似度
- 跨集角色形象统一

### 3.2 分镜设计

**分镜转化原则：**
- 每个片段明确：场景、人物、动作、台词
- 景别：特写/中景/全景
- 镜头运动：推/拉/摇/移

**完播率优化：**
- 开头30秒放置冲突镜头
- 分镜首帧1.5秒内设置"钩子"
- 可提升18%完播率

### 3.3 提示词优化

**提示词公式：**
```
详细描述场景 + 角色特征 + 动作 + 氛围
例：特写：女孩蓝色眼睛，泪珠滑落，悲伤表情
```

## 五、纳米漫剧流水线详细教程

### 第一步：准备剧本
```bash
1. 登录 namistory.com
2. 点击"新建作品"
3. 输入作品名称
4. 选择画面比例、创作模式、画面风格
```

### 第二步：输入剧本
```bash
1. 粘贴剧本到输入框
2. 点击【开始提取】场景/角色/道具
```

### 第三步：创建资产
```bash
1. 确认/调整场景设定
2. 确认/调整角色设定
3. 确认/调整道具设定
4. 不满意可点击重新生成
```

### 第四步：生成分镜
```bash
1. 选择分镜编剧智能体（推荐：解说版beta）
2. 调整生成设置
3. 点击自动生成分镜脚本
4. 等待几分钟
```

### 第五步：生成视频
```bash
1. 选择视频模型
2. 点击批量生成分镜视频
3. 预览整体效果
```

### 第六步：成片导出
```bash
1. 完整预览
2. 精细调整
3. 导出视频
```
