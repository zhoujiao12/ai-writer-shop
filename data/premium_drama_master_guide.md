## 🎬 第一部分：运镜技巧（大师级）

### 基础运镜

| 运镜 | 效果 | 使用场景 |
|-----|------|---------|
| **推** | 聚焦强调 | 情绪爆发、发现关键 |
| **拉** | 交代全貌 | 场景揭示、情绪疏离 |
| **摇** | 空间展示 | 室内外转、人物关系 |
| **移** | 跟随临场 | 追逐、行走、对话 |
| **跟** | 聚焦人物 | 核心人物动作 |
| **升降** | 气势变化 | 增强戏剧张力 |

### 高级运镜

| 运镜 | 说明 | 示例 |
|-----|------|------|
| **一镜到底** | 长时间不切换 | 追逐戏、情绪爆发 |
| **慢动作** | 强调细节 | 慢镜头打脸、眼泪滑落 |
| **快速剪辑** | 增强紧张感 | 冲突、追逐 |
| **长镜头** | 沉浸感 | 独白、情感戏 |
| **航拍** | 展示规模 | 大场面、府邸全景 |

### 剧情运镜公式

| 剧情 | 推荐运镜 | 效果 |
|-----|---------|------|
| **开场钩子** | 快速推进 + 特写 | 抓住眼球 |
| **情绪爆发** | 慢动作 + 特写 | 增强张力 |
| **打脸复仇** | 固定镜头 + 拉镜头 | 展现反转 |
| **浪漫场景** | 缓慢推进 + 柔光 | 温馨感 |
| **紧张悬疑** | 跟镜头 + 摇晃 | 增强不安 |

## 💡 第二部分：灯光设计（电影级）

### 灯光基础

| 光线 | 效果 | 情绪 |
|-----|------|------|
| **主光** | 主导光源，塑造形态 | 基础 |
| **补光** | 消除阴影 | 柔和 |
| **背光** | 轮廓光，分离主体 | 立体感 |
| **眼神光** | 眼睛有神 | 生动 |

### 灯光氛围公式

```
[光线类型] + [光源方向] + [色调] = [情绪氛围]
```

### 情景灯光对照表

| 情景 | 光线类型 | 光源方向 | 色调 | 氛围 |
|-----|---------|---------|------|------|
| **黎明/黄昏** | 侧光 | 低角度 | 暖橙 | 浪漫、温柔 |
| **正午** | 顶光 | 头顶 | 白/蓝 | 明亮、炎热 |
| **阴天** | 散射光 | 柔和均匀 | 灰蓝 | 压抑、悲伤 |
| **月光夜** | 冷色背光 | 斜上方 | 蓝白 | 神秘、幽静 |
| **烛光** | 暖散射 | 摇曳 | 橙黄 | 温馨、亲密 |
| **火光** | 暖闪烁 | 跳动 | 橙红 | 紧张、温暖 |
| **霓虹** | 彩色点光源 | 多角度 | 霓虹色 | 现代、赛博 |
| **手术灯** | 冷白强光 | 顶光 | 白 | 紧张、冷酷 |
| **夕阳** | 逆光 | 低角度 | 金橙 | 回忆、忧伤 |

### 情绪灯光公式

| 情绪 | 灯光公式 |
|-----|---------|
| **悲伤** | 头顶单灯 + 蓝色调 + 阴影 |
| **愤怒** | 红色调 + 底部打光 + 闪烁 |
| **浪漫** | 柔光箱 + 逆光 + 金色 |
| **悬疑** | 强对比 + 单侧光 + 阴影 |
| **希望** | 窗户光 + 暖色 + 尘埃感 |
| **绝望** | 顶灯单一 + 地面阴影 + 冷色 |
| **复仇** | 红色补光 + 深阴影 + 冷色 |
| **奢华** | 多点光源 + 金色调 + 闪烁 |

### 提示词写法

```
灯光：[light setup] + [color temperature] + [direction]

示例：
- "dramatic side lighting, warm golden hour from left, soft shadows"
- "cold blue backlight, ethereal glow, cinematic lighting"
- "warm candlelight flickering, orange tones, intimate atmosphere"
```

## 🏠 第三部分：空间逻辑（准确性）

### 空间基本原则

| 规则 | 说明 | 错误示例 |
|-----|------|---------|
| **不越轴** | 摄像机在关系线同一侧 | 突然跳到另一侧 |
| **不瞬移** | 有移动过程 | 上一镜门口，下一镜床上 |
| **视线一致** | A看B，下一镜B看A | B突然看别处 |
| **高度合理** | 站姿/坐姿/卧姿符合场景 | 站姿在矮房间 |

### 站位系统

#### 对话站位

```
          A ←─────→ B
          ↑视线    视线↑
          Camera (在同一侧)
```

#### 三人站位

```
        A (主)
       ↗   ↖
      B     C (次)
    Camera (侧面)
```

### 空间提示词

```
空间：[spatial logic] + [camera position]

示例：
- "A and B sitting opposite each other at wooden table, camera at eye level from side"
- "Character entering room from left door, walking toward center, continuous shot"
- "Two figures in bed, morning light from window on right side"
```

## 📐 第五部分：镜头连贯度

### 连贯性五要素

| 要素 | 检查 |
|-----|------|
| **位置** | 人物位置是否延续？ |
| **动作** | 动作是否衔接？（被推→落→挣扎） |
| **视线** | 视线是否一致？ |
| **光线** | 光源方向是否相同？ |
| **时间** | 时间流逝是否合理？ |

### 首尾帧衔接

```
镜1尾帧 = 镜2首帧（作为参考）

提示词：
"Seamlessly continuing from previous shot,
[动作延续],
maintaining spatial consistency"
```

### 衔接提示词模板

```markdown
镜头衔接：
- 位置延续："Character moving from left to right, continuous motion"
- 动作延续："Raising hand from previous position, arm fully extended"
- 视线延续："Looking in same direction as previous shot"
- 光线延续："Consistent golden hour lighting from left side"
```

## 📊 第七部分：情景运镜+灯光组合

### 复仇场景

```
开场：低角度仰拍 + 红色调 + 阴影
    → 增强压迫感和仇恨感

转折：快速剪辑 + 顶光 + 白色
    → 增强紧张和愤怒

结局：特写 + 逆光 + 金色
    → 增强复仇成功的爽感
```

### 浪漫场景

```
初遇：柔光 + 浅景深 + 暖色调
    → 增强浪漫氛围

表白：双人中景 + 逆光 + 金色散景
    → 增强梦幻感

圆满：升格镜头 + 日落光 + 暖色
    → 增强温馨感
```

### 悬疑场景

```
发现：手持跟拍 + 顶光 + 绿色调
    → 增强不安感

追踪：快速摇镜 + 侧光 + 深阴影
    → 增强紧张感

真相：固定镜头 + 单一点光源 + 黑白
    → 增强戏剧张力
```

## 🎓 第九部分：大师级技巧

### 技巧1：情绪对比蒙太奇

```
悲伤场景（冷色散射光）
    ↓ 快速切换
复仇场景（红色顶光）
    ↓ 快速切换
成功场景（暖色逆光）
```

### 技巧2：空间压缩

```
远景：展示府邸全貌
    ↓ 推进
中景：进入大门
    ↓ 推进
近景：走到正厅
    ↓ 推进
特写：主角表情
```

### 技巧3：光影叙事

```
好人出现 → 暖光
坏人出现 → 冷光/红光
主角觉醒 → 背光/轮廓光
反派落败 → 灯光变暗
```
