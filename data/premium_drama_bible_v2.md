## 🎯 爆款三原则

### 原则一：画面刺激
- 无论任何题材，吻戏、冲突场面必须有
- 第一集和投流片段必须先放出最有冲击力的画面
- 用极致的视觉冲击抓住眼球

### 原则二：剧情无脑
- 不用太在乎逻辑
- 不用思考每个人物动机
- **冲突性 > 逻辑性**
- **情绪性 > 故事性**

### 原则三：节奏爽快
- 每集都要有卡点
- 能吸引观众持续点开下一集
- 没有一丝喘气机会

## 🔥 黄金3秒法则

**开场必须用：最炸裂的冲突 + 最颠覆的身份 + 最极致的情感**

### 爆款开头公式

```
[身份错位] + [高冲突] = 瞬间抓住眼球
```

**示例：**
- "总裁撞见妻子出轨，西装革履却提着菜篮子"
- "被推入池塘的少女，其实是相府嫡女"
- "窝囊废女婿，突然亮出身份"

## 📈 情绪曲线公式

**优质短剧情绪曲线三个关键点：**

```
愤怒峰值 → 期待拐点 → 爽感高潮
（反派欺压）  （金手指）    （打脸复仇）
```

### 每集情绪要求

| 集数 | 任务 | 情绪 |
|-----|------|------|
| 1-4集 | 交代清楚世界观、人物、剧情 | 铺垫 |
| 5-8集 | 推进剧情，拉情绪到极致 | 高涨 |
| 9-10集 | 卡点留钩子，勾起付费意愿 | 悬念 |

## 🎬 男频战神套路

**核心：扮猪吃老虎，不停逆袭**

### 公式：
```
男主伪装成小人物
↓
配角不停打脸男主
↓
男主不断暴露身份
↓
反派"智障逻辑"（始终不相信）
↓
观众收获螺旋式爽感
```

### 反派设定：
- **不信逻辑**：即便所有证据摆在面前，反派就是不相信
- 以为男主收买了对方在做戏
- 或以为靠女人上位

### 禁区：
- 主角是战神，不能被打
- 主角是剧中权力最高的人，不能下跪
- 否则框架写崩

---

## 👩 女频复仇套路

**核心：情感。前期越悲情，后期越爽。**

### 公式：
```
渲染女主悲惨经历
↓
反派"找事逻辑"（不停地给女主制造麻烦）
↓
女主隐忍积累
↓
复仇打脸
↓
观众情绪爆发
```

### 常用悲情元素：
- 童年创伤
- 目睹亲人出事
- 生理缺陷
- 被陷害失去一切

### 反派设定：
- 要会"找事儿"
- 女主干什么，反派第一时间阻止
- 不需要太注重反派行为的逻辑性

---

## ✍️ 台词公式

### 核心原则：
> "角色用最简单的台词攻击对方，用最简单的手段打脸对方。"

### 具体要求：
- 大白话，不加修饰语
- 言简意赅
- 不要文艺腔
- 不用太在乎角色身份的文学性

### 示例：
```
❌ 错误：
"我深知此番离去恐难再相见，愿君珍重"

✅ 正确：
"这婚，我离了"
"滚"
"你给我等着"
```

## 🎬 剪辑功力

### 核心要点：
1. **气口**：精准的停顿
2. **配乐**：挑动情绪
3. **悬疑点**：剪辑出来加深冲突
4. **衔接**：每集严丝合缝，不留一秒多余

### 付费点控制：
- 10集、30集、60集必须有钩子
- 钩子后牵扯的剧情往往是：主角安然无恙，继续开挂

### 悬念设置：
| 类型 | 示例 |
|-----|------|
| 身份悬念 | 主角计谋是否被戳穿 |
| 身份曝光 | 主角身份是否将曝光 |
| 情感悬念 | 这巴掌是否会煽到女主脸上 |
| 新人物 | 加入新人物卖关子 |

## 📝 剧名公式

### 爆款剧名模板：

```
《X总，我又___》
《离婚/闪婚后，___》
《重生之___》
```

### 高频词：
- 首富、极品、总裁、夫人
- 娇妻、替身、虐恋
- 战神、龙王、嫡女

### 禁区：
- 主角不能姓王（喜感太强）
- 不能太文艺
- 不能太土（要土得恰到好处）

## 🎭 AI漫剧精品化要点

### 核心能力（技术闭环）：
1. **脚本自动生成**
2. **角色与场景资产锁定**（一致性！）
3. **分镜自动规划**
4. **图生视频**
5. **智能配音与口型同步**
6. **剪辑合成**

### 一人一剧工作流：
```
剧本 → 美术设定 → 资产建立 → 分镜 → Layout → 灯光特效合成 → 成片
```

### 角色一致性（核心！）：
- 跨镜头不能崩脸
- 风格统一性
- 使用参考图锁定

## 💰 免费模式趋势

### 趋势：
- 免费模式收益 > 付费模式
- 接受广告解锁的用户规模 >> 付费解锁
- 投流模式逐渐式微

### 策略：
- 内容足够优秀 → 无论是否投流都能爆
- 大浪淘沙 → 慢慢精品化
