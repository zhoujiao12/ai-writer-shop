## 二、关联词速查

### 1. 转折关系
```
虽然…但是… / 尽管…还是… / …却… / …然而… / …但是…
```

### 2. 假设关系
```
如果…就… / 要是…那么… / 即便…也… / 即使…也…
倘若…就… / 要是…就… / 倘若...便…
```

### 3. 并列关系
```
一边…一边… / 一会儿…一会儿… / 既…又…
又...又... / 一面...一面... / 有…有…
```

### 4. 递进关系
```
不但…而且… / 不光…也… / 不仅…还…
不但不…反而…
```

### 5. 选择关系
```
是…还是… / 要么…要么… / …或者...或者…
与其…不如… / 宁可(宁愿)…也不(决不)
```

### 6. 因果关系
```
因为…所以… / 之所以…是因为…
由于…因此… / 既然...也...
```

### 7. 条件关系
```
只要…就… / 只有…才…
无论(不论、不管、任凭)…都(也、还)...
```

### 8. 承接关系
```
一…就… / 首先…然后… / 首先…接着…
```

## 三、衔接词分类

### 按功能分类

| 功能 | 衔接词 |
|------|--------|
| **时间** | 原先、事先、很久以前、不久前、过不多久、随之、随后、接下来、曾几何时、顷刻之间、片刻 |
| **序列** | 首先，其次，最后、第一、一则，再则、其一、进一步说 |
| **加合** | 相应的、无独有偶、再说，此外，还有，更有甚者，此外，另外，补充一点，除此之外 |
| **真相** | 其实，实际上，确切的说，老师讲，不瞒你说，说句心里话 |
| **转折** | 要不、但是、不过、然偶、闲话少说、言归正传 |
| **条件** | 要是、不管怎样、无论如何、无论、不论、要不是这样、否则 |
| **让步** | 退一步说、自然、诚然、固然、当然 |
| **结果** | 终于、果然、不出所料、果不其然、果真、难怪、怪不得、原来如此 |
| **原因** | 所以、于是、因此、因而 |
| **解释** | 这就是说、换句话说、也就是说、具体来说、具体地说 |
| **补充** | 还有、另外、再说、补充一句、顺便说一下、附带说几句 |
| **归纳** | 总之、一句话、总的来看、总而言之 |
| **意外** | 谁知、哪料到、突然、猛然间、岂料、岂知、竟然、偏偏、可惜、不料、没想到、殊不知 |
| **推论** | 不用说、由此可见、显然、毫无疑问、可以肯定、这说明 |
| **比较** | 同样、相比之下、与此相比、相反、反之 |

## 五、黄金模板

### 模板1：转折式开头
```
原以为[正面预期]，谁知[意外结果]
本以为[假设]，不料[反转]
```

### 模板2：递进式推进
```
不仅[第一层]，甚至[第二层]
不但[基础]，而且[升级]
```

### 模板3：意外转折
```
本以为会[预期]，结果[反转]
让我没想到的是，[意外情况]
谁知[转折]
```

### 模板4：因果衔接
```
之所以[结果]，是因为[原因]
正因为[原因]，所以[结果]
```

## 六、实战应用技巧

### 1. 快速推进
```
下一秒，紧接着，随后，下一刻
→ 用短词加速节奏
```

### 2. 制造悬念
```
谁知，不料，竟然，偏偏，可惜
→ 用意外词制造转折
```

### 3. 情绪转折
```
然而，但是，却，不过
→ 用转折词切换情绪
```

### 4. 解释说明
```
原来，其实，实际上，说白了
→ 用解释词揭示真相
```

### 5. 总结归纳
```
总之，一句话，总而言之
→ 用归纳词收束情绪
```
