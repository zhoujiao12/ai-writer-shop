# 精品漫剧制作全流程 v1.0

> 从0到1完成一部精品AI漫剧
> 更新时间：2026-03-31

---

## 🎯 总览

```
策划 → 小说 → 分镜 → 生图 → 生视频 → 剪辑 → 发布
```

**时间预算：**
| 阶段 | 时长 |
|-----|------|
| 策划+小说 | 1小时 |
| 分镜设计 | 30分钟 |
| 生图 | 30分钟 |
| 生视频 | 1小时 |
| 剪辑+音效 | 1小时 |
| **总计** | **4小时/集** |

---

## 📋 阶段一：策划

### 1.1 确定题材

**爆款题材库：**
| 题材 | 爽点 | 目标人群 |
|-----|------|---------|
| 重生复仇 | 前世惨死+今生打脸 | 25-40岁女性 |
| 穿越逆袭 | 现代知识+古代开挂 | 18-35岁女性 |
| 霸总甜宠 | 高冷霸总+灰姑娘 | 18-30岁女性 |
| 婆媳矛盾 | 恶婆婆+反击 | 35-50岁女性 |
| 豪门恩怨 | 私生子+夺产 | 25-45岁全员 |

### 1.2 设定人物

**人物档案模板：**
```
【姓名】苏婉音
【年龄】16岁
【外貌】清秀绝美，眉心朱砂痣，左耳玉坠
【服装】素白汉服，淡蓝裙摆
【性格】外表柔弱，内心坚韧
【标志】眉心红痣（必须每镜一致）
```

### 1.3 设计爽点

**爽点密度要求：**
- 开头3秒：必须有一个钩子
- 每15秒：一个情绪爆点
- 每集结尾：必须有悬念

**爽点类型：**
| 类型 | 示例 |
|-----|------|
| 打脸 | 被羞辱后反击成功 |
| 逆袭 | 从底层爬到高位 |
| 真相大白 | 冤屈被洗清 |
| 复仇成功 | 恶人得到报应 |
| 爱情甜蜜 | 霸总宠溺 |

## 📝 阶段二：小说创作

### 2.1 分集大纲

**每集结构（60秒）：**
```
开头（0-10秒）：钩子，抓住注意力
发展（10-40秒）：情节推进
高潮（40-50秒）：情绪爆点
结尾（50-60秒）：悬念钩子
```

### 2.2 场景拆分

**场景数要求：**
- 60秒短剧：5-8个场景
- 每场景：5-10秒

**场景描述模板：**
```
【场景1】池塘边 · 黄昏
苏婉音被两个婆子拖向池塘，眼中含泪挣扎。
苏婉柔（画外音）："妹妹，做了丑事，就该浸猪笼！"
动作：苏婉音被推入池塘，冰冷的池水淹没她...
```

### 2.3 文案要求

**每场景文案：**
- 字数：20-50字
- 包含：人物 + 动作 + 情绪
- 避免抽象描述，要具象化

---

## 🎬 阶段三：分镜设计

### 3.1 景别规划

**景别呼吸原则：**
```
远 → 中 → 近 → 特写 → 退回中/远
```

**景别功能：**
| 景别 | 功能 | 示例 |
|-----|------|------|
| 远景 | 交代环境 | 府邸全景 |
| 中景 | 交代关系 | 两人对话 |
| 近景 | 表情情绪 | 面部表情 |
| 特写 | 强调细节 | 眼睛、手、物品 |

### 3.2 镜头运动

**镜头类型：**
| 镜头 | 叙事目的 |
|-----|---------|
| 推 | 聚焦情绪，强调 |
| 拉 | 交代环境，疏离 |
| 摇 | 展示空间关系 |
| 移 | 跟随人物移动 |
| 静 | 沉稳，对话 |

### 3.3 提示词编写

**图片提示词公式（Nano Banana Pro）：**
```
[Subject + Adjectives] doing [Action] in [Location].
[Composition/Camera Angle].
[Lighting/Atmosphere].
[Style/Media].
[Specific Constraint/Text].
```

**视频提示词公式（Grok Imagine）：**
```
Scene: [场景描述]
Subject: [主体+动作]
Camera: [镜头运动]
Lighting: [光线氛围]
Mood: [情绪基调]
Style: [风格类型]
Audio: [音效提示]
```

## 🎨 阶段四：图片生成

### 4.1 角色参考图

**先生成角色参考图！**
- 每个主要角色：1张正面参考图
- 上传到ZZDH人物库
- 后续生图时引用

**参考图要求：**
- 正面视角
- 表情中性
- 光线均匀
- 背景简洁

### 4.2 批量生图

**ZZDH操作流程：**
1. 选择图片模型（推荐：Gemini 3 Pro Image）
2. 批量选择所有分镜
3. 一键生成
4. 检查人物一致性
5. 不满意重新生成

**质量检查：**
- [ ] 人物外貌一致
- [ ] 场景合理
- [ ] 光线自然
- [ ] 无穿帮（如手指数量）

---

## 🎥 阶段五：视频生成

### 5.1 选择视频模型

**模型推荐：**
| 需求 | 推荐模型 | 原因 |
|-----|---------|------|
| 人物一致性 | Vidu R2V | 支持7张参考图 |
| 最便宜 | Vidu | ¥0.3/秒 |
| 最快 | Grok Imagine | 17秒生成 |
| 最长视频 | Kling | 支持2分钟 |
| 最高质量 | Sora 2 | 物理真实感 |

### 5.2 视频时长

**标准时长：**
- 每镜：5秒
- 总时长：不超过平台限制

**时长计算：**
```
60秒短剧 = 12镜 × 5秒
```

### 5.3 批量生成

**ZZDH操作流程：**
1. 切换视频模式
2. 选择视频模型
3. 设置时长（5秒）
4. 批量生成
5. 预览检查

---

## ✂️ 阶段六：剪辑

### 6.1 粗剪

**剪辑顺序：**
1. 导入所有视频片段
2. 按场景顺序排列
3. 调整时长（每镜5秒）
4. 检查流畅度

### 6.2 配音

**配音方式：**
- 方案A：AI配音（推荐：剪映AI配音）
- 方案B：真人配音

**配音要求：**
- 情绪到位
- 语速适中
- 不抢画面

### 6.3 音效

**音效类型：**
| 类型 | 示例 |
|-----|------|
| 环境音 | 风声、水声、脚步声 |
| 情绪音 | 心跳、倒吸凉气 |
| 转场音 | 滋滋声、whoosh |

### 6.4 字幕

**字幕要求：**
- 字体：清晰易读
- 位置：不挡画面重点
- 颜色：白色+描边
- 时长：与配音同步

### 6.5 BGM

**BGM选择：**
- 情绪匹配
- 不抢配音
- 有节奏感
- 版权清晰
