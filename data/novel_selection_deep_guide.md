## 🎯 核心框架速查

### 一、选书四大要素
```
设定新颖性 + 框架结构 + 爆点强度 + 热点结合
```

### 二、爽点构建公式
```
情绪缺口 → 金手指介入 → 缺口填补
```

### 三、文案三结构
```
开头（反差/反转/压情绪）→ 剧情推进（起承转合）→ 留钩子
```

### 四、起承转合写法
```
起：简写背景（1-2句）
承：简写但存在
转：适度详写
合：重点详写爽点
```

## 📋 一、审核禁忌详解

### 绝对红线
| 类型 | 处理方式 |
|------|----------|
| 黄 | 性器官描写删除，允许隐喻 |
| 赌 | 主角动机需正当（生存非牟利） |
| 毒 | 绝对禁止任何形式 |
| 黑 | 允许系统文，禁止主角害人 |
| 政 | 官场文限制县级范围 |
| 悬疑 | 允许脑洞灵异，禁止封建迷信 |
| 暴力 | "一刀毙命"替代血腥细节 |

## 📊 二、选书硬指标

### 平台标准
| 平台 | 字数 | 在读量 | 警惕 |
|------|------|--------|------|
| 番茄 | ≥30万 | ≥10万 | <30万且<10万在读 = 排除 |
| 七猫 | ≥30万 | - | 30万字内完结可能被砍文 |
| 书旗 | 同七猫 | 同七猫 | 需确认版权 |

### 排版排除标准
- 单章 >3000字不分段
- 单段 >500字
- 对话叙述混杂不分行

## 🎭 三、矛盾设计层级

### 三种矛盾类型
1. **人际矛盾**：校花嫌弃穷主角
2. **事件矛盾**：中彩票与负债对比
3. **环境矛盾**：末世求生困境

### 矛盾量级对比
```
低级矛盾：日常纠纷（买菜被坑）
    ↓
高级矛盾：种族存亡（人族最后希望）
```

**关键**：矛盾强度决定作品吸引力，需通过读者共情测试验证。

---

## 💥 四、爽点深度解析

### 爽点本质
> 情绪满足的完整闭环：**先制造缺口再填补**

### 经典三段式
```
① 矛盾激发：校花因穷分手
② 金手指介入：激活神豪系统获十亿
③ 情绪反转：校花跪求复合
```

### 关键手法
- **前置条件强化反差**：穷光蛋→暴富
- **道德制高点设计**：主角曾为对方支付学费
- **情绪曲线波动**：压抑→爆发形成V型起伏

### 情绪曲线类型
| 类型 | 曲线 | 适用 |
|------|------|------|
| 甜文 | 持续上扬 (1→2→3) | 纯爱 |
| 虐恋文 | 深V型（先抑后扬） | 虐文 |
| 扮猪吃虎 | 压制-逆袭对冲 | 爽文 |

## ✍️ 五、文案三结构详解

### 1️⃣ 开头技巧

#### 六大开头手法
| 手法 | 原理 | 案例 |
|------|------|------|
| 玩梗 | 流行梗共鸣 | 钓鱼毁一生→渔场系统 |
| 猎奇 | 极端设定 | 重生狮子+万次俯卧撑 |
| 反转 | 多层转折 | 神蛋→土狗→追杀→进化 |
| 压情绪 | 极端困境 | 86年饥荒+疯女人 |
| 噱头 | 身份反差 | 卖核武器被嘲笑 |
| 反差 | 常态vs非常态 | 钓鱼穷→钓鱼暴富 |

#### 开头模板
```
[普通事件] + [极端化处理] + [金手指介入]
```

#### 有效开头特征
- 形象具体（太平洋、金砖等可联想画面）
- 逻辑闭环（前后元素形成因果关系）
- 冲击力强（极端化对比）

#### 无效开头特征
- 元素断层（"狗和猪爬树"无关联）
- 抽象难懂（"肌肉痉挛"无画面感）
- 铺垫冗长（吃面与被抓无必要联系）

---

### 2️⃣ 剧情推进（起承转合）

#### 四阶段写法规则
| 阶段 | 内容 | 写法 | 篇幅 |
|------|------|------|------|
| 起 | 建立基础矛盾 | 简写背景 | 1-2句 |
| 承 | 矛盾升级 | 简写但需存在 | 最少 |
| 转 | 意外转折 | 适度详写 | 中等 |
| 合 | 解决矛盾+爽点 | 重点详写 | 最多 |

#### 经典案例
```
起：因贫穷遭女友分手（简写）
承：女友嘲讽主角穷困（简写）
转：获得神豪系统（适度详写）
合：女友跪求复合（重点详写）
```

#### 爽点详细写法示例
```
动作细节：膝盖磨破流血
神态描写：泪如雨下
行为刻画：紧抱裤脚哀求
```

---

### 3️⃣ 留钩子

#### 设置时机
- 冲突高潮处中断（如斗殴时突然亮刀）
- 新线索出现时（神秘人介入）

#### 要求
- 强悬念
- 自然停顿

## 🚫 六、正文三大禁忌

### 禁忌详解
| 禁忌 | 说明 | 反例 |
|------|------|------|
| 拖沓 | 事无巨细全写 | 吃饭睡觉都写 |
| 无关内容 | 偏离主线 | 与核心矛盾无关 |
| 原地打转 | 剧情不推进 | 纠结红苹果还是青苹果 |

### 正确做法
```
我要吃苹果 → 需要刀 → 下一句就是"我要去找到"
不能一直纠结"是吃红苹果还是青苹果"
```

## 📈 七、类型小说共性

### 四大类型套路
| 类型 | 核心设定 | 情绪缺口 |
|------|----------|----------|
| 末世文 | 前世被背叛→重生复仇 | 背叛创伤 |
| 历史文 | 重生废物太子/皇子 | 身份落差 |
| 种田文 | 失业后钓鱼触发剧情 | 生活困境 |
| 年代文 | 前世人渣→重生赎罪 | 道德反差 |

**底层逻辑**：所有类型都套用"制造情绪缺口→金手指填补"模型。

## ⚖️ 八、性别差异注意

### 男频 vs 女频
| 维度 | 男频 | 女频 |
|------|------|------|
| 情感拉扯 | 可能引发逻辑质疑 | 琅琊榜式剧情可接受 |
| 节奏要求 | 更快 | 可稍慢 |
| 爽点设计 | 直接暴力 | 情感满足 |

**关键**：同一剧情在不同频道的反应可能完全不同。

## 🎬 九、AI漫剧要点

### 核心认知
1. **文案质量决定传播**，特效仅短暂吸引
2. **精品化是误区**，需快速产出
3. **效率目标**：30分钟完成流程

### 电影解说受欢迎原因
- 节奏快
- 信息密度高
- 降低观众思考负担

## ✅ 十、实操检查清单

### 选书检查
```
□ 前3页是否有核心矛盾？
□ 金手指是否在压制后快速出现？
□ 情绪曲线是否完整（有压制有释放）？
□ 排版是否规范（分段清晰）？
□ 是否符合审核要求？
□ 爽点是否能一句话概括？
□ 是否有强烈代入感？
□ 是否超过平台最低标准？
```

### 文案检查
```
□ 开头是否有冲击力（反差/反转/压情绪）？
□ 起承转合是否完整？
□ 详写简写是否正确分配？
□ 是否有情绪波动？
□ 是否有钩子？
□ 是否避免了三大禁忌？
```

## 📚 十一、反例警示

### 《幻境》开篇问题
| 要素 | 问题 |
|------|------|
| 情绪压制 | 过度消耗读者耐心 |
| 金手指触发 | 与前期压制缺乏关联 |
| 情节转向 | 情绪链断裂 |

**核心缺陷**：
- 压制与释放脱节：7万字仍未收束
- 焦点模糊：从职业歧视突转情感纠纷
- 系统功能错配：战斗技能未解决核心矛盾
