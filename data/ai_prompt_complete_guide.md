# 第一部分：视频生成提示词（核心重点）

## 一、Sora 2 官方提示词结构（OpenAI官方指南）

### 核心原则
> "提示词是创意愿望清单，不是死板合同。给模型更多创作自由，可能带来意想不到的惊喜。"

### 标准提示词结构
```
[camera movement]: [establishing scene]. [additional details]
[镜头运动]: [场景描述]. [额外细节]
```

### 超详细电影级提示词模板
```
格式与外观
时长X秒；快门角度；胶片类型；颗粒感；光晕效果

镜头与滤镜
镜头焦段；滤镜类型

调色/色板
高光：色调描述
中间调：色调描述
暗部：色调描述

光线与氛围
主光位置和类型
补光方式
场景光源
氛围描述

地点与构图
场景位置
前景/中景/背景

服装/道具/群众演员
主要角色描述
群众演员描述
道具描述

音效
场景内音效描述

优化分镜表
[时间码] — [镜头名称]（镜头参数）
镜头描述
目的：镜头意图
```

### Sora 2 完整示例
```
格式与外观
时长4秒；180°快门；数字拍摄模仿65毫米胶片对比度；细颗粒感；
高光部分有轻微光晕；无胶片抖动。

镜头与滤镜
32mm/50mm球面定焦镜头；1/4黑柔焦滤镜；
轻微旋转环形偏振镜以控制火车车窗反光。

调色/色板
高光：带有琥珀色调的清晨阳光
中间调：平衡中性色，阴影部分略带青色
暗部：柔和中性黑色，为保留薄雾感而轻微提亮

光线与氛围
自然阳光从摄影机左侧以低角度射入（早上7:30）
补光：轨道旁使用4x4英尺银色反光板
场景光源：站台上的钠灯逐渐变暗
氛围：轻柔薄雾；火车废气飘过光束

地点与构图
城市通勤站台，黎明时分
前景：黄色安全线，长凳上的咖啡杯
中景：等待的乘客在薄雾中形成剪影
背景：进站的火车正在刹车

音效
仅场景内音效：微弱铁轨摩擦声，火车刹车嘶嘶声，
远处模糊广播声，低沉环境嗡嗡声
脚步声和纸张沙沙声；无配乐或后期音效

优化分镜表（2个镜头/总时长4秒）

0.00–2.40 — "抵达漂移"（32mm镜头，肩扛式缓慢向左移动）
镜头滑过站台标牌边缘；浅焦揭示出旅行者在画面中央，正望着轨道远方。
晨光在镜头中绽放；火车头灯在薄雾中柔和闪耀。
目的：建立场景和基调，暗示期待感。

2.40–4.00 — "转身停顿"（50mm镜头，缓慢弧线推近）
切到更近的过肩弧线镜头，火车停稳；旅行者稍微转向镜头，
阳光勾勒出脸颊轮廓，手机屏幕反射光芒。眼睛向上瞥向某个看不见的东西。
目的：用最少动作创造聚焦于人物的瞬间。
```

## 五、动作描述技巧（核心）

### 一镜一事原则
> 每个镜头应该只有一个摄影机运动和一个主体动作

### 用节拍描述动作

**错误写法：**
```
演员走过房间。
```

**正确写法：**
```
演员向窗户走了四步，停顿了一下，在最后一秒拉上了窗帘。
```

### 动作形容词库

| 类别 | 词汇 |
|-----|------|
| 速度 | 缓慢、快速、突然、逐渐、瞬间 |
| 力度 | 轻柔、粗暴、猛烈、颤抖、稳定 |
| 方向 | 向上、向下、向前、向后、环绕 |
| 情绪 | 紧张、放松、愤怒、悲伤、喜悦 |
| 方式 | 优雅地、笨拙地、犹豫地、果断地 |

## 七、Grok Imagine (xAI) 提示词黄金公式

### 核心公式
```
[主体] + [动作/运动] + [摄像机运动] + [视觉风格] + [音频方向]
```

### 五个核心要素

| 要素 | 描述 | 示例 |
|-----|------|------|
| 主体 | 清晰描述主要角色/物体 | "一只带有虹彩鳞片的绯红巨龙" |
| 动作/运动 | 定义具体的运动 | "穿过风暴云层翱翔，翅膀制造出风力涡流" |
| 摄像机运动 | 控制视角变化 | "慢平移", "360° 环绕", "缩小", "追踪镜头" |
| 视觉风格 | 设定美学方向 | "电影级光效", "赛博朋克美学", "写实主义" |
| 音频方向 | 指定声音氛围 | "史诗般的管弦乐起伏", "脉冲低音", "引擎轰鸣" |

### 关键技巧

- **前 20-30 个词最重要**：Grok 会优先处理提示词的开头部分
- **避免负面描述**：Grok 对"无模糊"之类的词反应不佳 —— 请使用正面描述
- **保持简洁**：50-150 个词效果最佳；视频提示词应保持在 200 个字符以内
- **动作要具体**：使用"缓慢摆动臀部"而不是模糊的"移动"

### Grok Imagine 提示词示例

**电影大片级：**
```
一名手持发光长剑的孤独战士在摇摇欲坠的城堡塔顶与巨龙战斗，
电影级宽镜头，黄金时刻光效，戏剧性的风暴云，慢动作火花飞溅，
史诗幻想风格
```

**赛博朋克：**
```
霓虹闪烁的东京街头，赛博朋克黑客，湿滑路面上的雨水反射，
周围漂浮着全息界面，动态低角度镜头，紫色和蓝色霓虹光效，
未来主义美学
```

**动漫风格：**
```
动漫女孩特写，鲜艳的配色，纤细的轮廓，闪亮的眼睛，
赛璐珞渲染的头发，戏剧性的风效
```

## 八、CogVideoX 智谱提示词公式

### 核心公式
```
提示词 = (镜头语言 + 景别角度 + 光影) + 主体 (主体描述) + 主体运动 + 场景 (场景描述) + (氛围)
```

### 提示词构成详解

| 要素 | 说明 | 示例 |
|-----|------|------|
| 镜头语言 | 镜头运动方式 | 镜头平移、推近、拉远、升降拍摄、摇摄、跟随拍摄 |
| 景别角度 | 相机与被摄对象距离和角度 | 大全景、中景、近景、鸟瞰视角、跟随视角 |
| 光影 | 光线效果 | 自然光、丁达尔效应、柔和散射、硬光直射、逆光剪影 |
| 主体 | 主要表现对象 | 儿童、狮子、向日葵、汽车、城堡 |
| 主体描述 | 外貌细节和肢体姿态 | 服饰、毛色、颜色、状态、风格 |
| 主体运动 | 运动状态 | 静止和运动（符合6s视频内可以展现） |
| 场景 | 主体所处环境 | 前景、背景 |
| 场景描述 | 环境细节 | 都市环境、乡村风光、工业区 |
| 氛围 | 预期氛围 | 喧嚣繁忙、悬疑惊悚、宁静舒适 |

### 提示词技巧

1. **关键词重复**：在提示的不同部分重复或强化关键词
   - 如：摄像机以**超高速**镜头**快速**飞过森林

2. **聚焦内容**：提示词应集中在视频中应有的内容
   - ✅ 冷清的街道
   - ❌ 没有人的街道

### CogVideoX 示例

**示例1：**
```
比得兔（主体）开小汽车（主体描述），
游走在马路上（环境描述），
脸上的表情充满开心喜悦（氛围设定）
```

**示例2：**
```
特写镜头（镜头描述），傍晚的微光（光线运用），
一只鹦鹉站在阳台的栏杆上，
鹦鹉有着紫色的羽毛和粉色的喙（主体描述），
背景是都市的高楼大厦（环境描述）。
```

## 三、Adobe Firefly 提示词原则

### 四大原则

1. **尽量具体明确**
   - 至少使用三个词语
   - 避免使用"生成"或"创建"等词语
   - 坚持使用简明直接的语句

2. **清楚描述**
   - 描述越详细，越有可能获得符合构想的图像
   - 包含主体、描述词和关键词

3. **坚持原创**
   - 融入感觉、风格和灯光元素
   - 将独特视角融入提示中

4. **富有同理心**
   - 使用"爱心"、"轻柔"、"俏皮"等词语生成温馨图像
   - 使用"有力"、"强大"、"令人振奋"等词语生成鼓舞人心的图像

# 第四部分：叙事型提示词写作法

## 一、我之前的问题根源

| 问题 | 具体表现 | 正确做法 |
|-----|---------|---------|
| ❌ 没有镜头运动 | 只写"镜头缓慢推进"，千篇一律 | 指定具体的镜头类型和运动方式 |
| ❌ 没有时间流 | 没有描述从开始到结束的过程 | 用"开始...然后...最后..."描述时间序列 |
| ❌ 表情与文案不匹配 | 文案说"痛苦"，提示词写"平静" | 根据文案情感设计表情变化 |
| ❌ 用抽象词代替具体描述 | "电影质感"太泛 | 使用具体的光线、色调、焦段描述 |
| ❌ 没有动作序列 | 没有描述动作的变化过程 | 用节拍方式描述动作 |

## 三、提示词写作六步法

### Step 1: 明确目标
- 这个镜头要表达什么情绪？
- 核心动作是什么？
- 视觉重点在哪里？

### Step 2: 具体化描述
- 不要只说"痛苦"，要说"眉头紧锁、眼睛紧闭、牙关咬紧"
- 不要只说"美丽"，要说"暖红色的烛光映照着精致的面容"

### Step 3: 添加视觉元素
- 颜色：暖红色调、冷蓝色调
- 光线：侧光、背光、漫射光
- 环境：雕梁画栋、纱幔轻垂

### Step 4: 注重动作动态
- 时间序列：开始...然后...最后...
- 动作过程：猛然、缓缓、快速

### Step 5: 多重角度视角
- 镜头类型：大特写、近景、中景
- 镜头运动：推、拉、摇、移、跟

### Step 6: 反复优化
- 检查是否与文案情绪匹配
- 检查是否有时间流
- 检查是否有具体的动作描述
