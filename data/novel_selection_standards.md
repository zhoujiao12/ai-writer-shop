# 小说筛选执行标准

> 来源：第二天文案课笔记
> 整理日期：2026-03-25

---

## 一、审核禁忌（红线）

### 绝对禁止
- 黄赌毒、涉黑、涉政
- 大明星名字、国家领导人名字
- 主角三观不正

### 特殊处理
| 类型 | 处理方式 |
|------|----------|
| 涉黄 | 性器官描写需删除，允许隐喻表达 |
| 涉赌 | 主角动机需正当（为生存非牟利） |
| 涉毒 | 绝对禁止任何形式 |
| 涉黑 | 允许系统文/脑洞文，禁止主角害人 |
| 涉政 | 官场文限制在县级范围 |
| 悬疑 | 允许脑洞灵异，禁止封建迷信 |
| 暴力 | 避免"血腥细节"，用"一刀毙命"简略表述 |

## 二、选书核心要素

### 1. 四大要素
- **设定新颖性**：重生动物视角等非常规设定
- **框架结构**：先抑后扬、信息差、纯爽文
- **爆点强度**：一句话概括核心亮点（如"核能心脏打爆地球"）
- **热点结合**：及时捕捉社会热点改编

### 2. 网文构造五要素

| 要素 | 定义 | 应用要点 |
|------|------|----------|
| 矛盾 | 激发情绪的关键点 | 人际/事件/环境多维度矛盾 |
| 爽点 | 满足读者心理需求 | 逆袭、碾压等情节设计 |
| 期待感 | 维持阅读动力 | 明确目标与阶段性成果 |
| 代入感 | 读者身份认同 | 强化主角视角与共性体验 |
| 画面感 | 场景呈现效果 | 视频改编需突出视觉化元素 |

## 三、选书标准

### ✅ 必须满足
1. **矛盾集中**：前3页出现核心冲突
2. **爽点连贯**：情绪曲线完整
3. **金手指及时**：压制后快速反转（不超过1集）
4. **排版规范**：分段清晰，每段3-5行

### ❌ 直接排除
| 问题类型 | 识别特征 |
|----------|----------|
| 新手/AI作品 | 长篇大论、未分段、内容密集 |
| 矛盾缓慢 | 通篇描写环境，迟迟不展现核心矛盾 |
| 金手指太慢 | 被嘲讽后只说"给我等着"就回家 |
| 主角圣母 | 末世救所有人、优柔寡断 |
| 情绪中断 | 压制后7万字仍未收束 |

### 平台指标
| 平台 | 字数要求 | 在读量 | 注意事项 |
|------|----------|--------|----------|
| 番茄 | ≥30万字 | ≥10万在读 | 回避短篇完结作品 |
| 七猫 | ≥30万字 | 无保底砍文 | 拒绝30万字内完结 |
| 书旗 | 同七猫 | 同七猫 | 需确认版权 |

## 四、爽点构建原理

### 核心公式
```
情绪缺口 → 金手指介入 → 缺口填补
```

### 经典案例
```
前提：打工供女友三年学费 → 因买不起LV包被分手
转折：激活神豪系统获得十亿现金
结果：前女友跪求复合
```

### 情绪曲线类型
- **甜文**：持续上扬（1→2→3）
- **虐恋文**：先抑后扬（深V型）
- **扮猪吃虎**：压制-逆袭对冲

### 三要素关系
1. **矛盾**：必须真实合理
2. **代入感**：普世价值观共鸣
3. **爽点**：金手指填平情绪缺口

## 五、文案三结构

### 1. 开头（快速吸引）
**手法**：反差、反转、压情绪

**有效案例**：
- "女人碰一滴水就会死，却每天在太平洋游几个来回"
- "百万富翁每天捡矿泉水瓶卖钱"
- "乞丐用黄金碗乞讨"

**无效案例**：
- 元素断层（"狗和猪爬树"无关联）
- 抽象难懂（"肌肉痉挛"无画面感）

### 2. 剧情推进（起承转合）
| 阶段 | 内容 | 写法 |
|------|------|------|
| 起 | 建立基础矛盾 | 简写背景 |
| 承 | 矛盾升级 | 简写但需存在 |
| 转 | 意外转折 | 适度详写 |
| 合 | 解决矛盾+爽点 | 重点详写 |

### 3. 留钩子
- 冲突高潮处中断（如斗殴时突然亮刀）
- 满足强悬念+自然停顿

## 六、正文操作

### 转折词运用
- 虽然...但是
- 因为...所以
- 即便如此

### 精简原则
- 背景设定：最大限度压缩
- 核心爽点：展开描写
- 过渡内容：保留必要逻辑链
- 支线内容：基本不写，服务于主线

## 七、反例警示

### 《幻境》开篇问题
| 结构要素 | 问题诊断 |
|----------|----------|
| 情绪压制 | 过度消耗读者耐心 |
| 金手指触发 | 与前期压制缺乏关联 |
| 情节转向 | 情绪链断裂 |

**核心缺陷**：
- 压制与释放脱节：7万字仍未收束校花线
- 焦点模糊：从职业歧视突转情感纠纷
- 系统功能错配：战斗技能未解决核心矛盾

## 八、快速筛选检查清单

```
□ 前3页是否有核心矛盾？
□ 金手指是否在压制后快速出现？
□ 情绪曲线是否完整（有压制有释放）？
□ 排版是否规范（分段清晰）？
□ 是否符合审核要求（无禁忌内容）？
□ 爽点是否能一句话概括？
□ 是否有强烈代入感（普世价值观）？
```

## 十、AI漫剧要点

1. **文案质量决定传播效果**，特效画面仅短暂吸引注意力
2. **追求精品化制作是误区**，需注重快速产出
3. **电影解说受欢迎原因**：节奏快、信息密度高、降低观众思考负担
4. **效率目标**：完整流程控制在30分钟内
