## 🔥 第二步：题材爆款公式

### 现代女频（霸总/虐恋/甜宠）
```
开头：身份反差 + 冲突现场
中段：打脸反击 + 甜宠互动
结尾：高潮反转 + 悬念钩子
```

### 古风女频（重生/宅斗/宫斗）
```
开头：前世惨死 + 重生归来
中段：步步为营 + 复仇打脸
结尾：大仇得报 + 新悬念
```

### 其他题材
参照上述规律类推，注意情绪强度和爽点密度

## 💥 第三步：情绪爆点设计

### 七大情绪类型
爽感 | 虐心 | 愤怒 | 期待 | 甜蜜 | 恐惧 | 搞笑

### 情绪爆点分布
```
开头3秒：首爆点（必须！）
中段每30秒：中小爆点
结尾前：尾爆点（钩子）
```

---

## ✍️ 第四步：小说改文技巧

### 黄金3秒原则
```
原文：环境描写 + 铺垫 → 改后：冲突现场 + 爆点前置
```

### 对白精简原则
```
原文：文艺腔/长句 → 改后：短句/直接/有力（≤10字）
```

### 情绪外化原则
```
原文：内心独白 → 改后：动作/表情/生理反应
```

## 🎬 第五步：分镜改编

### 分镜密度体系

| 版本 | 千字分镜数 | 单镜时长 |
|-----|-----------|---------|
| 6秒版 | 135个 | 2-4秒 |
| 10秒版 | 67个 | 3-6秒 |
| 15秒版 | 45个 | 3-8秒 |

### 蒙太奇三大风格

| 版本 | 镜头数 | 单镜时长 | 适合场景 |
|-----|--------|---------|---------|
| **快切版** | 6-10个 | 0.3-1.2秒 | 打脸/爆发/爽点 |
| **转场版** | 3-5个 | 1-8秒 | 场景切换/时空跳跃 |
| **长镜头版** | 1-2个 | 7-15秒 | 情感戏/暧昧/压迫 |

### 五维提示词架构
```
@参考对象 + 主体描述 + 核心动作链 + 镜头与光影 + 动漫化特效
```

## 🤖 第八步：模型适配（关键！）

### 各模型提示词差异

| 模型 | 语言 | 风格 | 时长 | 价格 |
|-----|------|------|------|------|
| Grok | 英文为主 | 电影写实 | 10-17秒 | ¥0.35/秒 |
| Sora | 英文为主 | 电影写实 | 10秒 | $0.20/秒 |
| **Vidu** | 中英均可 | **动漫最强** | **4-8秒** | **¥0.3/秒** |
| 即梦 | 中文 | 动漫 | 6-15秒 | ¥0.73/秒 |

### Grok/Sora → Vidu 转换

| 元素 | Grok/Sora | Vidu适配 |
|-----|-----------|---------|
| 运镜 | Dolly-in, Tracking | 推进、跟拍、环绕 |
| 光线 | volumetric god rays | 体积光、柔光 |
| 色调 | cinematic, desaturated | 动漫渲染、鲜艳色彩 |
| 风格 | photorealistic | Japanese anime style |

### Vidu专用提示词公式
```
Scene: [场景]
Subject: [主体+动作]
Camera: [运镜] [景别]
Light: [光线]
Mood: [情绪]
Duration: [X]s
Ref: [参考图]
```

### Vidu首尾帧控制
```
首帧（起点） + 过渡描述 + 尾帧（终点）

示例：
首帧: 公主站在宫殿中央手放下
尾帧: 公主手抬起，凤冠羽毛飘动
过渡: 镜头推进，体积光汇聚
时长: 5秒
```

## 🚀 快速执行流程

```
Step 1: 接收小说 → 分析题材 → 确定情绪主线
Step 2: 应用黄金3秒公式 → 强化冲突 → 简化台词
Step 3: 分配分镜密度 → 选择蒙太奇风格
Step 4: 生成图片提示词
Step 5: 生成视频提示词（适配目标模型）
Step 6: 质量自检 → 输出交付
```
