## 🎯 技能概述

本技能包实现从小说文本到AI漫剧视频的全自动化流程，涵盖：
1. 小说筛选与评估
2. 剧本改编与分镜设计
3. AI图片生成提示词
4. AI视频生成提示词
5. 多模型适配与优化

## 🔧 模块详解

### 模块1: 小说筛选器

**输入**: 小说文本或URL
**输出**: 评估报告 + 改编建议

**筛选标准**:
| 维度 | 权重 | 评分标准 |
|------|------|----------|
| 矛盾强度 | 25% | S/A/B/C/D |
| 金手指时效 | 20% | 压制后多久出现 |
| 情绪曲线 | 20% | 完整性评分 |
| 代入感 | 15% | 普世痛点强度 |
| 排版质量 | 10% | 分段/标点 |
| 平台指标 | 10% | 字数/在读 |

**爆款线**: 总分 ≥ 80分

---

### 模块2: 剧本改编器

**输入**: 小说文本 + 筛选报告
**输出**: 改编剧本

**改编模板**:

#### 重生复仇类
```
前世[具体惨状] → 重生回[关键时刻] → 这一次[复仇宣言]
```

#### 系统觉醒类
```
[具体困境] → [金手指出现] → [实力反转]
```

#### 身份反差类
```
所有人以为[表面身份] → 其实[真实身份] → 当[真相揭露]时
```

#### 极端困境类
```
[极端困境] + [时间限制] → [生存威胁] → [反击开始]
```

### 模块5: 视频提示词生成器

**四种视频生成模式**:

| 模式 | 输入 | 用途 |
|------|------|------|
| **文生视频** | 仅文字提示词 | 纯想象创作 |
| **图生视频** | 提示词 + 参考图 | 让图片动起来 |
| **首帧生视频** | 提示词 + 首帧图 | 控制开头 |
| **首尾帧生视频** | 提示词 + 首帧图 + 尾帧图 | 控制开头和结尾 |

**核心原则**:
1. 一镜一事：一个摄影机运动 + 一个主体动作
2. 五感触发：先"看/听/感觉"，才能"想/说/做"
3. 景别呼吸：远→中→近→特写→退回中/远
4. 时长严格：总时长严格不超过限制
5. 对白精简：按版本控制对白数量和单句长度
6. 镜头有动机：景别变化必须有叙事目的
7. 衔接自然：使用正确关联词，避免重复
8. 结尾钩子：最后一个镜头必须是特写卡点
9. 忠实原文：不添加原文没有的内容

---

### 模块6: 视频合成器

**输入**: 视频片段 + 配音 + 配乐
**输出**: 成片

**合成参数**:
- 分辨率: 1080x1920 (竖屏)
- 帧率: 24fps
- 格式: MP4
- 编码: H.264

## 🎯 模型选择决策树

```
需要首尾帧控制？
├── 是 → Veo3.1（高端）或 Seedance（国产）
└── 否
    └── 需要长视频（>1分钟）？
        ├── 是 → Kling
        └── 否
            └── 需要最快速度？
                ├── 是 → Grok Imagine (17秒)
                └── 否
                    └── 需要角色一致性？
                        ├── 是 → Vidu（动漫）或 Sora2（真实）
                        └── 否
                            └── 预算有限？
                                ├── 是 → Vidu（¥0.3/秒最便宜）
                                └── 否 → 按需求选择
```
