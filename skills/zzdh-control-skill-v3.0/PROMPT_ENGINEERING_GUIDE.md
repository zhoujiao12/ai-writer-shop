## 第一部分：文生视频 vs 图生视频 - 提示词核心区别

### 一、文生视频（Text-to-Video）

**核心特点：从零开始，AI需要想象一切**

| 项目 | 说明 |
|-----|------|
| **输入** | 仅文字提示词 |
| **AI任务** | 想象主体、场景、运动、光影、镜头 |
| **难度** | 高 - AI需要全量幻觉补全 |
| **可控性** | 低 - 结果不可预测 |
| **适用场景** | 快速测试、灵感启发、简单场景 |

**文生视频提示词公式（阿里云百炼官方）：**

```
提示词 = 主体 + 场景 + 运动
```

**进阶公式：**
```
提示词 = 主体（主体描述）+ 场景（场景描述）+ 运动（运动描述）+ 美学控制 + 风格化
```

**可灵官方公式：**
```
提示词 = 主体（主体描述）+ 运动 + 场景（场景描述）+（镜头语言 + 光影 + 氛围）
```

**文生视频示例：**
```
基础版：一只猫在雪地里玩雪球

进阶版：一只毛茸茸的小奶猫，橘白相间的毛发，戴着红色小铃铛项圈，
在冬日清晨的雪地庭院里玩雪球，它用前爪滚起一个雪球，笨拙地推着前进，
雪球突然裂开，它惊跳后退，打了个喷嚏又好奇凑近。
低角度拍摄，暖色调，柔和晨光，童趣温馨氛围。
```

**文生视频的核心问题：**
1. **角色不一致** - 跨场景角色会变化
2. **场景不稳定** - 背景会闪烁或变化
3. **物理不准确** - 运动可能不符合物理规律
4. **细节丢失** - AI想象的内容可能偏离预期

### 二、图生视频（Image-to-Video）

**核心特点：图片已确定主体、场景与风格，只需描述运动**

| 项目 | 说明 |
|-----|------|
| **输入** | 图片 + 文字提示词 |
| **AI任务** | 让图片动起来，描述运动过程 |
| **难度** | 低 - 已有视觉参考 |
| **可控性** | 高 - 结果可预测 |
| **适用场景** | 专业制作、角色一致、商业应用 |

**图生视频提示词公式（阿里云百炼官方）：**
```
提示词 = 运动 + 运镜
```

**图生视频与文生视频的本质区别：**

| 对比项 | 文生视频 | 图生视频 |
|--------|---------|---------|
| **提示词重点** | 描述"有什么"（主体、场景、运动） | 描述"怎么动"（运动、运镜） |
| **主体描述** | 需要详细描述主体外观 | ❌ 不需要，图片已确定 |
| **场景描述** | 需要详细描述环境 | ❌ 不需要，图片已确定 |
| **风格描述** | 需要描述画面风格 | ❌ 不需要，图片已确定 |
| **运动描述** | 描述主体+非主体的运动 | 描述图片中元素的运动 |
| **运镜控制** | 可选 | 重要 - 控制镜头移动 |
| **提示词长度** | 长（100-300字） | 短（20-100字） |

**图生视频示例：**

原图：一个女孩坐在窗边看书

```
文生视频提示词（错误示范）：
一个穿白色连衣裙的女孩，长发，坐在窗边，阳光从窗户照进来，
她在安静地看书，偶尔翻页，背景是书房，书架上有很多书...
（❌ 错误：重复描述图片已有的内容）

图生视频提示词（正确示范）：
女孩轻轻翻过书页，偶尔抬头望向窗外，发丝随风轻轻飘动，
镜头缓慢推进，固定镜头。
（✅ 正确：只描述运动和运镜）
```

**图生视频提示词要点：**
1. **不要重复描述图片内容** - 图片已有主体、场景、风格
2. **重点描述运动** - 主体动作、表情变化、环境动态
3. **运镜要明确** - 镜头推进、拉远、平移、固定
4. **形容词控制速度** - 快速地、缓慢地、轻轻地

### 三、首帧生视频（First-Frame-to-Video）

**核心特点：控制视频的开头，AI推断后续**

| 项目 | 说明 |
|-----|------|
| **输入** | 首帧图片 + 文字提示词 |
| **AI任务** | 从首帧开始，按照提示词发展 |
| **可控性** | 中 - 开头确定，结尾不确定 |
| **适用场景** | 故事开场、明确的开头画面 |

**首帧生视频提示词公式：**
```
提示词 = 从首帧开始的动作描述 + 发展方向 + 镜头控制
```

**首帧生视频示例：**

首帧：一个男人站在悬崖边，背对镜头

```
提示词：
男人缓缓转身，面向镜头，风吹动他的风衣，他凝视远方，
镜头缓慢推近至面部特写。
```

**首帧质量决定视频质量：**
- 首帧分辨率越高，视频质量越好
- 首帧构图要合理，留有运动空间
- 首帧光线要明确，便于AI理解光源

---

### 四、首尾帧生视频（Keyframe-to-Video）

**核心特点：控制开头和结尾，AI填充中间过渡**

| 项目 | 说明 |
|-----|------|
| **输入** | 首帧图片 + 尾帧图片 + 文字提示词 |
| **AI任务** | 从首帧过渡到尾帧 |
| **可控性** | 最高 - 开头和结尾都确定 |
| **适用场景** | 过渡动画、前后对比、揭示变化 |

**首尾帧生视频提示词公式：**
```
提示词 = 过渡方式 + 运动描述 + 时间节奏
```

**首尾帧生视频的核心逻辑：**

| 概念 | 说明 |
|-----|------|
| **首帧** | 视觉起点 - 视频从哪里开始 |
| **尾帧** | 视觉终点 - 视频到哪里结束 |
| **提示词** | 过渡指导 - 如何从首帧到尾帧 |

**首尾帧生视频的工作原理：**

```
首帧 ──────────────────────→ 尾帧
(起点)    AI填充中间内容    (终点)
          ↑
       提示词指导过渡方式
```

**首尾帧生视频示例：**

首帧：整洁的书桌，书整齐排列
尾帧：凌乱的书桌，书散落一地

```
提示词（过渡版）：
书桌从整洁逐渐变得凌乱，书本一本接一本掉落，
平滑过渡，自然变化，2秒过渡时间。

提示词（动作版）：
一只手愤怒地扫过书桌，将书本全部扫落在地，
快速动作，暴力破坏，镜头固定。
```

**首尾帧生视频的运用场景：**

| 场景 | 首帧 | 尾帧 | 提示词重点 |
|-----|------|------|-----------|
| **时间流逝** | 白天场景 | 夜晚场景 | "从白天过渡到夜晚，自然变化" |
| **改造变身** | 原始状态 | 改造后状态 | "逐渐变化，揭示改造过程" |
| **前后对比** | 产品使用前 | 产品使用后 | "展示使用效果，对比变化" |
| **情感转变** | 开心表情 | 悲伤表情 | "表情从开心转变为悲伤" |
| **空间移动** | 室内 | 室外 | "从室内走到室外，跟随镜头" |

**首尾帧生视频注意事项：**

1. **首尾帧要有关联性** - 相同的角色、场景或主题
2. **过渡要合理** - 不能首帧是人，尾帧变成狗
3. **提示词描述过渡方式** - 快速、缓慢、平滑、剧烈
4. **时间戳可选** - 指定过渡发生在第几秒

## 第二部分：文生图 vs 图生图 - 提示词核心区别

### 一、文生图（Text-to-Image）

**核心特点：凭空生成，AI需要想象画面**

**文生图提示词公式（通用）：**
```
提示词 = 主体 + 细节描述 + 环境 + 风格 + 质量词 + 参数
```

**Midjourney公式：**
```
提示词 = 主体描述 + 环境场景 + 艺术风格 + --ar 比例 --v 版本
```

**Stable Diffusion公式：**
```
正向提示词 = 主体 + 特征 + 环境 + 质量 + 风格
反向提示词 = 不想要的内容（如 bad hands, blurry）
```

**文生图示例：**
```
Midjourney：
a beautiful girl with long black hair, sitting on a sofa,
wearing a white dress, soft lighting, cozy living room,
anime style, high detail --ar 16:9 --v 6

Stable Diffusion：
正向：(masterpiece, best quality), 1girl, long black hair,
white dress, sitting on sofa, soft lighting, cozy room

反向：bad hands, missing fingers, extra digit, fewer digits,
cropped, low quality, normal quality, jpeg artifacts
```

---

### 二、图生图（Image-to-Image / img2img）

**核心特点：基于参考图重绘，控制变化程度**

**图生图与文生图的核心区别：**

| 对比项 | 文生图 | 图生图 |
|--------|--------|--------|
| **输入** | 仅文字提示词 | 图片 + 文字提示词 |
| **AI任务** | 从零生成 | 基于参考图重绘 |
| **核心参数** | 种子、步数、CFG | **重绘强度（Denoising Strength）** |
| **可控性** | 低 | 高 |

**图生图的核心参数：重绘强度（Denoising Strength）**

| 重绘强度 | 效果 | 用途 |
|---------|------|------|
| **0.1-0.3** | 微调 | 修复细节、轻微调整颜色 |
| **0.3-0.5** | 中等变化 | 改变风格、调整构图 |
| **0.5-0.7** | 大幅变化 | 风格转换、角色改造 |
| **0.7-1.0** | 几乎重画 | 完全改变内容 |

**图生图提示词原则：**

1. **重绘强度低时（<0.4）**：
   - ❌ 不需要重复描述参考图内容
   - ✅ 只需要描述想要改变的部分
   - 示例：参考图是一个女孩，只想改变发色
   ```
   提示词：blue hair（仅描述改变部分）
   重绘强度：0.3
   ```

2. **重绘强度高时（>0.5）**：
   - ✅ 需要添加颜色、风格相关提示词
   - 参考图只作为构图参考
   - 示例：真人照片转二次元
   ```
   提示词：anime style, cel shading, vibrant colors
   重绘强度：0.65
   ```

**图生图常见应用：**

| 应用 | 重绘强度 | 提示词重点 |
|-----|---------|-----------|
| **风格转换** | 0.5-0.7 | 风格词：anime, oil painting, watercolor |
| **线稿上色** | 0.4-0.6 | 颜色词：colorful, vibrant colors |
| **细节修复** | 0.2-0.4 | 质量词：high detail, sharp focus |
| **局部修改** | 0.3-0.5 | 变化部分描述 |

## 第五部分：专业提示词模板

### 文生视频模板

```
【主体】一位年轻的女性，黑色长发，穿着白色连衣裙
【场景】坐在窗边，阳光从窗户照进来，书房背景
【运动】轻轻翻书页，偶尔抬头望向窗外，发丝随风飘动
【镜头】缓慢推进，从全景到中景
【光影】柔和晨光，侧逆光，暖色调
【氛围】安静、温馨、文艺

完整提示词：
一位年轻的女性，黑色长发，穿着白色连衣裙，坐在窗边的书房里。
阳光从窗户照进来，形成柔和的侧逆光。她轻轻翻过书页，偶尔抬头望向窗外，
发丝随风轻轻飘动。镜头缓慢推进，从全景过渡到中景。暖色调，安静温馨的氛围。
```

### 图生视频模板

```
【图片内容】（不要在提示词中重复）
【运动描述】女孩轻轻翻书，抬头看窗外，发丝飘动
【运镜】固定镜头，保持构图
【速度】缓慢、自然、轻柔

完整提示词：
女孩轻轻翻过书页，偶尔抬头望向窗外，发丝随风轻轻飘动。
固定镜头，保持原有构图，缓慢自然的运动节奏。
```

### 首尾帧生视频模板

```
【首帧】整洁的房间
【尾帧】凌乱的房间
【过渡方式】快速变化
【运动描述】书本一本本掉落，椅子翻倒
【时间】3秒过渡

完整提示词：
房间从整洁快速变得凌乱，书本一本接一本掉落在地，
椅子翻倒，纸张飞舞。快速剧烈的变化，3秒过渡时间。
```

## 总结：核心记忆点

1. **文生视频** = 描述"有什么" + "怎么动"
2. **图生视频** = 只描述"怎么动"（运动+运镜）
3. **首帧生视频** = 控制开头，AI推断后续
4. **首尾帧生视频** = 控制开头+结尾，AI填充过渡
5. **文生图** = 从零想象，需要完整描述
6. **图生图** = 基于参考图，重绘强度控制变化程度

**关键原则：不要重复描述已有内容！**
