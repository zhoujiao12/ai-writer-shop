## 四种视频生成模式

### 1. 文生视频 (Text-to-Video)
```
输入：仅文字提示词
输出：视频
```

**适用场景：**
- 没有任何参考图
- 纯想象创作
- 快速测试

**支持模型：** 所有视频模型

---

### 2. 图生视频 (Image-to-Video)
```
输入：文字提示词 + 参考图片
输出：视频（图片会动起来）
```

**适用场景：**
- 有现成的角色/场景图
- 想让静态图片动起来
- 保持角色一致性

**支持模型：**
- wan2.6-i2v
- kling系列
- vidu系列
- 海螺系列

---

### 3. 首帧生视频 (First-Frame-to-Video)
```
输入：第一帧图片 + 文字提示词
输出：从第一帧开始的视频
```

**适用场景：**
- 有明确的开头画面
- 想控制视频的开头
- 故事开场

**支持模型：**
- Sora2
- 蛤肉系列
- wan2.6-i2v
- 豆包Seedance

---

### 4. 首尾帧生视频 (Keyframe-to-Video)
```
输入：第一帧图片 + 最后一帧图片 + 文字提示词
输出：从第一帧过渡到最后一帧的视频
```

**适用场景：**
- 想控制开头和结尾
- 过渡动画
- 前后对比

**支持模型：**
- Veo系列
- 豆包Seedance
- wan2.2-kf2v-flash

## 各模型特点（Tavily深度搜索 2026-03-28）

### Sora2 (OpenAI)
- **官网**: sora.chatgpt.com
- **发布**: 2025年9月
- **特点**:
  - **物理级真实感** - 物体永久性、真实运动
  - **音画同步** - 原生音频生成，口型完美同步
  - **角色一致性** - 多个场景中角色保持一致
  - **场景持久化** - 复杂多镜头叙事连贯
  - **Cameos功能** - 可将自己/人物插入视频中
- **支持**: 文生视频、首帧生视频、多镜头序列
- **语言**: 英文提示词
- **价格**: 通过 ChatGPT Plus 访问
- **对比其他**: 被称为视频生成的"GPT-3.5时刻"

### Veo3.1 (Google DeepMind)
- **官网**: ai.google.dev
- **特点**:
  - **高保真8秒视频** - 最高4K分辨率
  - **原生音频生成** - 视频自带音效
  - **首尾帧控制** - 精确控制开头和结尾
  - **平滑过渡** - 4-8秒视频无缝过渡
- **支持**: 文生视频、首帧生视频、首尾帧生视频
- **语言**: 英文提示词
- **价格**:
  - 720p/1080p: $0.20/秒（无音频）/$0.40/秒（有音频）
  - 4K: $0.40/秒（无音频）/$0.60/秒（有音频）
  - 例：5秒1080p带音频 = $2.00

### Kling 可灵 (快手)
- **官网**: app.klingai.com
- **特点**:
  - **长视频支持** - 最长2分钟（其他通常10-60秒）
  - **电影级质量** - 1080p分辨率，30fps
  - **图生视频强** - 专业模式增强视觉质量
  - **3D时空建模** - 真实物理运动
  - **扩散Transformer架构** - 专有3D VAE网络
- **支持**: 文生视频、图生视频
- **语言**: 中文提示词
- **对比优势**: 比其他模型生成更长视频，灵活宽高比

### Vidu AI
- **官网**: vidu.com
- **特点**:
  - **Reference to Video** - 多参考图生成，角色一致性极强
  - **动漫风格最佳** - 社区公认动漫风格最优秀
  - **多实体一致性** - 非照片级角色保持一致，"纯魔法"
  - **快速生成** - 分钟级生成
  - **音视频同步** - 同步音频生成
- **支持**: 文生视频、图生视频、参考图生视频
- **语言**: 中英文
- **定位**: 短视频创意工具，营销增强

- **支持**: 文生视频、图生视频、首尾帧生视频

## ZZDH中的实际使用

### 在ZZDH中操作流程

1. **选择视频模型**：在设置或生成界面选择
2. **系统自动判断模式**：根据是否设置了首帧/尾帧
3. **自动匹配**：
   - 有首帧+尾帧 → 首尾帧生视频
   - 只有首帧 → 首帧生视频
   - 有参考图（图生模型）→ 图生视频
